## 1 深读语料中创新点的四类归纳

对 79 篇深读论文的创新点逐条归并，可划为四类（同一篇可有多个）：

### 类型 I：记忆表示与检索架构创新（约 24 篇，红海）

**主张模式**：新的记忆组织单元/索引/检索算子 → 在 LoCoMo/LongMemEval/Video-MME 等 QA 基准上涨分。
- 代表：SYNAPSE（扩散激活）、CAST（场景-角色双记忆）、MemCoRe（Merge/Link/Append 门控+IB 形式化）、xMemory（解耦-聚合+回溯重组）、E-mem（engram 多智能体持有原始上下文）、FluxMem（结构可学习指派+BMM 软门控）、DCPM（supersedes 双链）、Hindsight/TEMPR（四网络+信念演化）、Infini Memory（可维护主题文档+seq/time/source 签名）、MIRIX（六类记忆路由）、G-Memory（MAS 三层图）、WorldMM（多时间尺度 KG+视觉双通道+自适应模态检索）、Light-Omni（反射优于推理）、EventMemAgent（事件四元组）、ScrapMem（光学遗忘）、video-SALMONN S（TTT 快权重）、MemVerse（CLS 双通路+蒸馏）、LMEE（RL 主动记忆查询）、MemGen（潜在记忆）、SAGE 图记忆（GFM reader）、FORGE（种群广播）、RoMeRL（降阶效用状态）、BMAM（脑区组件化）、MMA（元认知置信层）。
- **风险信号**：LoCoMo 类基准接近饱和（DCPM 自述 plateau；Hindsight 83.6%、SYNAPSE 40.5 F1 等），纯架构创新边际收益递减；EvoMemBench F1 发现"长上下文基线极强"，WorldMemArena 发现"存储召回高≠性能好"——架构刷分的范式正被评测学反思瓦解。

### 类型 II：记忆维护/治理创新（约 15 篇，快速升温）

**主张模式**：让记忆"写得对、信得过、忘得掉"——写时冲突消解、置信治理、遗忘、安全。
- 写时维护：WorldMM Consolidate、ReflectWorld-MM Add/Update/Delete、MemCoRe Conflicts 边、AgeMem（RL 学 Update/Delete 原语）、Infini Memory 写时 recency override、xMemory 回溯重组。
- 置信与降权：MMA（来源/时间/共识→abstain）、TAME（贡献归因降权+信任标注）、BMAM（再巩固+EMA 置信度）、LightMem（置信衰减遗忘）、CMI（plasticity/stability/poisoning 三轴诊断+检索选择器增广训练）。
- 安全：MemLineage（溯源+authority repair）、A-MemGuard（共识验证+负教训）、SSGM（治理蓝图+漂移上界定理）、MemSecBench（修复评测协议）、MemoryGraft/OEP/MEXTRA（攻击面）。
- **关键上限证据（本题机会所在）**：Infini Memory FC-MH 81.0→58.0（写时固化无法保证跨文档一致性）；DCPM 自述 supersedes 链误判无纠错算子；LightMem 错误注入证明"写入污染→持续下游污染→级联放大"且系统无法自恢复；MemSecBench SRSR 仅 56.1%（修复附带损伤是主因）；WorldMemArena"append-only 主导"。

### 类型 III：自进化/RSI 闭环创新（约 20 篇，2026 年爆发）

**主张模式**：失败/反馈信号 → 定位改进对象 → 受控局部修改 → 验证门控准入 → 跨任务复用。
- 诊断-修复-门控范式定型：**Recuris**（结构化 trace 归因 64.8% vs 仅结果 13.0%；组件级 scoped patch；验证门）、HarnessFix（HTIR 证据链+回归感知验证）、ModularRSI（成败轨迹对比+五模块受限演化，joint 反而掉分）、ScienceBuddy（有界单点编辑+配对验证防回归）、AutoMem（失败→模块诊断→text gradient）。
- 正则化与统计基础：RRSI（编辑预算/噪声地板/泄漏筛查/L1 剪枝）、MERID（不确定性缩放接受裕度+保留裕度界）、PAST-Bench（机制证据分 Mech+wrong-mechanism 对照）。
- 对象光谱：harness 代码（多数）→ 记忆架构（MemEvolve/AutoMem）→ 技能（PEAM 参数内化、KnowAct-GUIClaw 原位修复、SAGE RL）→ 经验条目（ReMe 效用删除、G-Memory 洞察图、FORGE 整库广播）→ 任务内工作记忆（VideoLoop Update/Append/Delete）→ 具身经验条目（CMMR-VLN first-error 定点写回）→ 视频域 harness（Video-RSI active investigation）。
- 数据/权重侧对照（与冻结基座相斥但构成光谱两端）：NeoHorse-1（路由数据飞轮 SFT+蒸馏）、Gödel Forest（数据合成训练）、ScienceBuddy 外递归 RL、AgeMem、SAGE 技能 RL、MemoryExplorer GRPO。

### 类型 IV：评测协议与基准创新（约 14 篇，评测学转向）

**主张模式**：从端到端准确率走向**过程诊断**与**修复评测**。
- 阶段诊断：WorldMemArena（Write/Maintain/Retrieve/Use 四阶段+gold memory points）、substrate 评测（2608.15008，7 家族 26 指标）、EvoMemBench（in/cross-episode×knowledge/execution 四象限）。
- 修复评测：MemSecBench（七 checkpoint+SRSR=恶意移除∧良性保留）、PAST-Bench（Update 能力轴+E5 overwrite 机制）、Mem-Gallery（KR/CD/AR 知识管理轴）、HaluMem/False Memory Rate（综述引）、ICM-Bench（身份错链证据）、MMA-Bench（信念动态逻辑矩阵）。
- RSI 评测：PAST-Bench（自进化 gap Δ 配对归因）、EvoMemBench（元进化代表仅 MemEvolve 一个）、AI2 harness 评测（预算对等红线，池外）。

## 2 本选题可主张的创新点（与证据逐条对应）

> 选题假设：冻结基座下，M3-Agent 式多模态视频记忆的证据驱动错误定位 + 最小化局部修复 + 跨任务策略进化。撞车判定详见 collision_check.md（部分覆盖；组合空间未被占位）。

### C1（主张一）：首个面向 M3-Agent 类**多模态记忆内容**的证据驱动条目级错误定位任务与机制

- **可主张的具体内容**：定义"记忆内容错误"分类学（实体错链／幻觉事件／时间错锚／模态错配／过时未修订），构建跨模态证据链（记忆条目 → 源片段/时间区间/模态 → 依赖条目），在任务失败信号驱动下做多步归因定位，并**报告定位精度**。
- **支撑证据（空白存在）**：
  - Storage-to-Experience 综述原话：多模态记忆"Reflection 与 Experience 阶段的工作极其稀缺"；
  - Agent Memory 第二半综述 §9.5：多模态记忆缺 action-conditioned 更新与跨层一致性维护的原则性机制；§9.6：缺 provenance/audit/rollback；
  - ICM-Bench 实证 M3-Agent 存在身份错链错误（把不同人的观察链接到同一身份）且宽泛 QA 分数掩盖该失灵；
  - 现有最近邻均不到位：Recuris 定位对象是文本技能/控制组件；Video-RSI 定位对象是 harness 代码；CMMR-VLN 只做单步 first-error+3 类手工标签；MMA 只打置信分不归因。
- **可复用方法**：Recuris 的三条件归因实验（result-only 13.0% / raw trajectory 37.0% / structured trace 64.8%）可直接移植为视频记忆版定位实验设计——这本身就是一条可发表的实验发现。
- **撞车风险**：中高（Video-RSI 证明"证据驱动诊断"在视频域可行，差距只在对象层；需以月频监控其后续）。

### C2（主张二）：**最小化局部修复（minimal patch）**算子 + preservation 约束 + 不确定性缩放的准入统计

- **可主张的具体内容**：修复动作限定为条目级 patch（修订属性/撤错误链/时间重锚/增补证据，而非重建记忆或重灌上下文）；修复后必须通过"修复源任务 ∧ held-out 不回归 ∧ 良性记忆保留率 ≥ 阈值 ∧ 增益超不确定性缩放裕度"的准入门。
- **支撑证据（preservation 是公认痛点）**：
  - MemSecBench：F1（恶意移除）86.3% vs F2（良性保留）62.5%，SRSR 仅 56.1%，"修复附带损伤是主要失败源"——preservation 指标有现成定义可借；
  - MERID：接受裕度随验证集不确定性缩放（0.047 裕度拒绝 0.039 增益的实例）+保留裕度理论界——修复准入的统计基础可直接引用；
  - Infini Memory FC-MH（81.0→58.0）与 DCPM 失败模式：证明"全量重写/写时固化"路线有结构性上限，局部修复有必要性；
  - ModularRSI：joint 全局修改掉分、受限修改涨分——"局部化本身是收益来源"有直接消融证据；
  - WorldMemArena：461 任务实证当前系统 append-only 主导、极少修订删除。
- **评测设计现成模板**：PAST-Bench 的 stale/wrong-mechanism 对照 + 机制证据分；CMI 的暴露前/暴露后两段失败定位。
- **撞车风险**：中（写时维护族与任务内 VideoLoop 是最近邻；差异在"任务失败驱动的事后修复"+preservation 约束）。

### C3（主张三）：修复经验沉淀为**跨任务记忆策略版本**（D/w/P 三层中的 P 层），带门控准入与迁移验证

- **可主张的具体内容**：修复产生的不是一次性改动而是可版本化的记忆策略（何时触发修复、按什么证据模式定位、用何种 patch 算子），策略库按版本保存、按验证门准入、跨视频/跨任务复用并报告迁移增益与不回退检查。
- **支撑证据（跨任务策略层在多模态域空白）**：
  - Recuris 已证明"策略/组件经验跨任务+跨模型迁移有效"（文本技能域，35/37 提升）——机制合法性有据，但域为文本；
  - Storage-to-Experience 综述把"从多模态轨迹簇提取模态不变策略先验"明确列为 Experience 层未来工作；
  - EvoMemBench F6/F8：瓶颈在"形成可复用知识"而非"存更多"，且迁移取决于记忆形态与目标决策过程的匹配——为策略版本设计提供评测依据；
  - RRSI：正则化使演化集收益与迁移收益解耦（6 个 held-out 不回退）——迁移协议模板；
  - Video-RSI 演化产物（结构化观察接口/关系图证据复用）证明视频域策略工件可复用——但其对象仍是 harness 代码。
- **撞车风险**：中高（Recuris 直接适配到多模态记忆即最近竞争形态；本地已有其复现，可快速做出"Recuris 风格直接适配"对照——这恰是本选题相对优势：比任何外部团队更快验证该对照）。

### 不宜主张（已被占位，写作时避开）

1. "记忆需要可编辑/可修订"这一命题本身（WorldMM、ReflectWorld-MM 已占）；
2. "检索端置信降权/弃权"（MMA、TAME、SYNAPSE 已占）；
3. "记忆系统架构元进化"（MemEvolve、AutoMem 已占）；
4. "冻结 VLM+长视频+递归自改进"的泛表述（VideoHarness-RSI/Video-RSI 已占）；
5. "任务内工作记忆的证据级编辑"（VideoLoop 已占）；
6. "记忆修复评测协议"本身作为主贡献（MemSecBench、PAST-Bench 已占）——可作次级贡献或评测章节。

## 3 创新点组合的独特性验证

三维交集检验（80 卡范围内）：

| 维度 | 取值 | 占位者 | 与本题交集 |
|---|---|---|---|
| 对象 | 记忆**内容**条目 | WorldMM/ReflectWorld-MM（写时）、VideoLoop（任务内工作记忆）、CMMR-VLN（经验条目） | 无人做长期记忆内容的**事后**修复 |
| 证据 | 跨模态证据链回访 | Video-RSI（harness 层）、Recuris（文本 trace） | 无人做记忆条目级的视觉-文本对齐归因 |
| 进化 | 跨任务策略版本 | Recuris（文本技能）、MemEvolve（架构）、Video-RSI（harness 工件） | 无人做多模态记忆策略版本沉淀 |

**结论**：三维交集为空 → 组合创新点（C1×C2×C3 打包）成立；但任一单维主张都不新，论文表述必须始终以"组合+限定词"出现（多模态记忆内容级、证据驱动、最小化 patch、跨任务策略、冻结基座——五个限定词缺一即撞车）。
