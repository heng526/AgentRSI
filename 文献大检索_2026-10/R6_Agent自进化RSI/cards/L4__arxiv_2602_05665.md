# Graph-based Agent Memory: Taxonomy, Techniques, and Applications (2026, arXiv 2602.05665, PolyU/厦大/SMU/JLU 综述)

## 问题与动机
- LLM agent 三大固有短板：知识截止、工具能力弱、长程迭代任务性能饱和（"反复犯同类错误、无学习行为"）。记忆是通向个性化、超上下文长程推理、self-improving（无参数更新的任务内自改进）与幻觉抑制的关键模块。
- 传统记忆（定长窗口、向量库、KV/log）是平面/隐式结构，缺关系建模、层次组织、因果依赖。图结构（KG/时序图/超图/层次图/混合图）成为 2025-2026 agent 记忆前沿；传统记忆可视为图的退化形式（线性 buffer=链，向量库=相似度加权全连接图）。

## 方法拆解（综述框架而非单一方法）
- **分类学**：短期 vs 长期；认知结构六类（semantic/procedural/associative/working/episodic/sentiment）；知识记忆（被动静态、客观可验证）vs 经验记忆（主动动态、交互轨迹与反馈）；非结构 vs 结构；图作为统一视角。
- **生命周期四阶段**：
  - Extraction：文本（三元组抽取/嵌入/摘要）、轨迹（事件分割+时间戳、动态状态快照、模式挖掘→程序性记忆模板）、多模态（VLM/音频 caption、交互内容、联合嵌入）；
  - Storage：KG（LLM 抽取+Mem0 式冲突检测/关系剪枝/schema 演化）、层次树（语义聚类+递归摘要，MemTree/SGMEM）、时序图（Graphiti 双时间线 valid/transaction time、TReMu 解耦 mention/event time、MemoTime 层次时间单调性约束防逻辑幻觉）、超图（HyperGraphRAG 保 n 元关系完整性）、混合架构（知识-经验解耦）；
  - Retrieval：六类算子（相似度/规则/时间/图遍历（层内+层间）/RL/agent）+ 三类增强（多轮检索、后检索、混合源）；
  - **Evolution（与本选题最相关）**：Internal Self-Evolving（记忆固化=子图合并成 schema 节点+LLM 语义门控评估信息增益；推理与冲突消解="A⟹B 而 C⟹¬B 时按置信度/时间新近性触发 self-correction 更新图"；潜在链接预测；归纳知识丰富；图重组=显著性剪枝+拓扑优化）＋ External Self-Exploration（反馈驱动：ExpeL/Matrix 成功轨迹结晶为技能、失败轨迹对比分析隔离因果错误编码"教训"；Memory-R1/Inside-Out 把记忆操作当 RL 动作；MemEvolve 进化存储结构本身。主动探查：ProMem 检测图中缺失节点/歧义边自生成查询、AgentEvolver 自生成子任务、KIMI K2.5 并行 swarm 探索）。
- **训练方式**：覆盖范围含免训练 prompt 式与 RL 训练记忆操作两条线。

## 数据与实验
- 综述无自建实验。整理了 11 个开源记忆库对比（Cognee、Mem0、OpenMemory、MemMachine、Memary、Graphiti、LangMem、LightMem、O-Mem、Memori 等）。
- Benchmark 七场景分类：Interaction（多轮/跨会话）、Personalization、Web（长程浏览）、LongContext、Continual（终身学习，指出"缺标准化报告，遗忘/迁移指标不一，且难辨收益来自参数更新还是日志检索"）、Environments（具身）、Tool/Gen。
- 资源库：github.com/DEEP-PolyU/Awesome-GraphMemory。

## 创新点
1. 以图为统一表示统一 agent 记忆设计空间（传统记忆=退化图）。
2. 把 Memory Evolution 明确拆为 Internal Self-Evolving / External Self-Exploration 双范式，并把"冲突触发的 self-correction"与"失败轨迹因果错误隔离"纳入演化分类。
3. 提出记忆图多维质量观（结构/语义/时间/操作四维）并指出内在质量度量稀缺。

## 局限（其指出的 open challenges）
- 记忆图质量：缺显式评估记忆图内在质量的指标——即"错误记忆如何被发现与度量"尚无系统方案。
- 可扩展性：图操作二次方以上复杂度，需增量更新/近似检索。
- 安全：图记忆易受记忆投毒/对抗操纵，需内容验证、异常检测、健壮审计协议（defense 列为 future work，无具体机制）。
- 动态 schema 学习与跨域迁移不足。
