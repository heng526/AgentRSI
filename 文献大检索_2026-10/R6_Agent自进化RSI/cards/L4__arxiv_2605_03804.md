# ScrapMem: A Bio-inspired Framework for On-device Personalized Agent Memory via Optical Forgetting (2026, arXiv 2605.03804 v2, 南京农业大学/南京大学)

## 问题与动机
- 边缘设备上的长期个性化多模态记忆：存储成本高、多模态复杂。参数记忆灾难性遗忘+不可解释；检索式难对齐文本/视觉/语音异构模态，因果与时序推理弱；多模态存储对资源受限设备开销过高。
- 灵感三源：CLS 理论（海马快速绑定情景、新皮层缓慢固化）、人类剪贴簿实践（异构材料聚合为场景中心页）、DeepSeek-OCR 发现（图像作为信息载体比文本 token 压缩近一个量级）→"视觉即压缩存储+保真度随时间衰减=光学遗忘"。

## 方法拆解
- **Agent 架构**：三阶段管线——(1) Scrapbook Page 固化与光学感知：按时序把照片/视频/文本/行为记录聚合为剪贴簿页 S_t；视觉编码器出视觉 token Z_t，OCR 出文本 T_t，caption/摘要函数 g(·) 把视觉 token 投影为文本，LLM 抽取语义节点，原始视觉 token 直接作为显式视觉节点，形成混合节点集 V_t=X_LLM(T_t⊕g(Z_t))∪Z_t；索引-内容分离（页保留原始多模态证据，节点服务检索）。
- **记忆读写机制**：EM-Graph 情景记忆图 G=(V,P)——页内相关节点组织为 EM-Path（有序事件链，如诊断→治疗→康复），显式二值节点-路径关联矩阵 Q∈{0,1}^(|P|×|V|) 支持查询节点与路径的节点重叠匹配，返回 top-k EM-Path 作为证据作答。
- **进化或修复闭环**：Optical Forgetting——把遗忘形式化为时间间隔 τ 的有损变换 S_t^(τ)=D_τ(S_t)（渐进降分辨率、消解琐碎视觉与冗余文本细节）；被遗忘页的混合节点集收缩为显著子集 V_t^(τ)⊆V_t，无法可靠感知的节点被删除、含失效节点的 EM-Path 被剪枝，得演化图 G^(τ)。这是"时间驱动+分辨率驱动"的遗忘/剪枝，不是错误驱动的修复。
- **训练方式**：免训练组合现成模型（视觉编码器+OCR+LLM），面向 on-device 部署。

## 数据与实验
- ATM-Bench（4 年真实个人数据：邮件/图像/视频）：指标 QS（答题）、R@10（检索）、Joint@10（端到端），题型分 Number/List Recall/Open-ended。
- 主结果：ScrapMem (No-Forget) QS 52.5 / R@10 70.3 / Joint@10 51.0（SOTA），vs 最强基线 ATM-RAG(SGM) QS 51.0/R@10 68.7/Joint@10 48.6、Self-RAG(SGM) 50.3/68.7/48.2、HippoRAG2(SGM) 47.7/69.6/46.9、A-Mem(Piled) 46.1/66.6/44.0、Mem0(Agentic) 43.5/61.9/41.8；带遗忘的完整版 QS 48.4/R@10 66.1/Joint@10 46.9。
- 遗忘敏感性/存储：最高 93% 存储削减、保留峰值性能 90% 以上（Joint@10 46.3%）；其他配置 88–92% 存储削减、性能波动小。
- 附录失败分析（与本选题相关）：三类失败占比——检索失败 58.6%、LLM 推理失败 29.4%、光学遗忘失败 12.0%；含"正确事件错误日期""从错误事件抽数值""压缩页丢失答题所需细节（多为老证据、压缩最激进处）"等 10 个典型案例。

## 创新点
1. 首个把"光学/分辨率衰减"作为多模态记忆的遗忘算子（视觉即存储介质、保真度=遗忘程度的连续旋钮），解耦存储占用与端到端性能。
2. EM-Path+关联矩阵 Q 的路径级检索单元（而非节点级），支持退化视觉下的多跳因果-时序推理。
3. 给出带失败类型占比的失败分类学（检索/推理/遗忘三源）。

## 局限
- 遗忘是时间驱动不可逆过程：被压掉的细节无法恢复，遗忘失败（12%）无补救机制；无错误检测——记忆错了只会被"降分辨率"而不会被修正。
- 无冲突检测与矛盾消解（时间近邻但语义冲突的记忆如何处理未涉及）。
- 剪贴簿页的时序切分粒度、显著性节点判定均为启发式；场景限于个人助理 referential QA（ATM-Bench），无任务执行/策略进化。
- No-Forget 版反而全面优于带遗忘版（52.5 vs 48.4 QS），遗忘的价值只在存储侧，质量侧为负收益。

## 与本选题关系
- **撞车风险：低**。
- **overlap**：同为多模态（含视频）记忆架构的记忆维护问题——其"遗忘失败"类别与附录失败分类学证明作者已意识到"记忆系统自身会制造错误"，与我们"记忆错误定位"的问题意识相邻；多分辨率退化的记忆表示与 3DLLM-Mem 的空间记忆粒度思想有亲缘。
- **difference_from_ours**：ScrapMem 的记忆演化只有"遗忘"一种算子且由时间驱动，没有证据驱动的错误定位、没有修复写入、没有跨任务策略进化；其失败分析是人工离线归因而非在线机制。可作为"记忆维护=遗忘 only"现状的代表引用，反衬我们"定位-修复"算子的缺失；其 12% 遗忘失败占比可引用说明信息损失型维护的代价。
