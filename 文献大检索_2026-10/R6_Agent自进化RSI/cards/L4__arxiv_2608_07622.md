# Controlled Memory Interference in Continual LLM Agents (2026, arXiv 2608.07622)

## 问题与动机
记忆进化不只是"多存"：新经验可能强化、修订或干扰既有记忆状态。多条记忆同时相关但在状态/时间效力/权威性上不同（旧偏好被新更新取代、重复经历过度强化过时状态）——类比人类记忆的 proactive interference 与 cue overload，称为 **memory interference**。现有系统强调构建与相关性检索，不管"检索到的记忆是否适合当前状态"。干扰比检索失败广：干扰记忆可能阻止目标进入上下文（暴露前失败），或目标被检索但未引导决策（暴露后失败）。任务总准确率无法定位是哪种关系导致错误、失败发生在暴露前还是后。

## 方法拆解
- **CMI 框架**：受控诊断+数据生成。记忆集三分 M+（目标）/M^c（竞争：被取代状态、瞬态例外、同槽冲突、误导更新）/M^o（背景）。控制变量：load L0–L6（数量）、关系构成（matched neutral/unrelated/repeated history/same-slot conflict，计数 0/2/4/8）、fixed-L3 authority probe（P0 普通噪声/P1 近期瞬态/P2 持久更新/P3 权威纠正）。配对变体保持 query/期望决策/目标位置不变，差异全部归因受控添加。实例化为 CMI-Travel（MemoryArena TravelPlanner 扩展），并迁移到 PERMA/LongMemEval/HorizonBench/MEME Tracking。
- **评测维度**：Plasticity（采纳有效更新）、Stability（保留既有状态）、Poisoning resistance（拒绝误导更新），明确不假设对称 stability–plasticity 权衡。检索诊断指标：target exposure T、competing exposure C、preference ordering PO、MRR；retrieval-to-decision 分解 P(A|T)（目标被暴露后采纳的条件概率）。
- **干预**：IAAR——轻量（逻辑回归类）检索选择器，仅用可观察检索状态特征做 lexical–dense 自适应选择；用 CMI 生成的干扰样本做 in-domain 增广训练（interference-aware memory learning）。

## 数据与实验
TravelPlanner（Qwen3-Embedding-8B 为主，另验 E5-Mistral-7B/NV-Embed-v2/Linq-Embed-Mistral）：count-8 时（基线 P0=0.84, S0=0.92）——Lexical 下 repeated history 使 plasticity −0.34、same-slot conflict −0.50（stability 几乎不变）；Dense 下 unrelated −0.18、repeated history −0.46、same-slot conflict −0.44 且 stability 0.92→0.54（联合退化）。路径分解：Lexical same-slot conflict 是纯检索瓶颈（Target R@3 0.34、竞争独占暴露 0.66、但 P(A|T)=1.00）；Dense 两阶段皆败（recall 0.48–0.54，P(A|T) 0.741–0.792）。四编码器稳健性：count-8 Target R@3 损失 repeated history 0.22–0.68、same-slot 0.42–0.58。跨数据集 L0→L6：Lexical plasticity −0.720～−0.940（stability ≤ +0.022）。权威性：P0/P1 毒化接受率 0.02/0.02（Lexical），P2 持久更新 0.23、P3 权威措辞 0.26——**角色线索比 recency 更驱动中毒**。IAAR：CMI 增广训练使 Target R@3 +0.114～+0.614、MRR +0.041～+0.426、noisy-update 答对率 +0.114～+0.614（全部配对 CI 排除零，clean 点估计不降）；但 frozen selector 跨编码器失准（Qwen +0.144 vs E5 −0.009）。

## 创新点
1. 首个把记忆间**关系**（而非数量）作为受控变量诊断持续 agent 记忆失败的框架，发现"选择性 plasticity 压制"且不对称于 stability；2. retrieval-to-decision 两段式失败定位（暴露前 vs 暴露后）；3. 证明"传达的更新角色/权威性"而非 recency 驱动毒化接受；4. CMI 样本可直接作训练增广（可操作的治疗性数据生成）。

## 局限
文本偏好/旅行规划域，无多模态；IAAR 只改检索排序不改记忆内容本身（竞争记忆召回仍高、PO 改善有限），不修复错误记忆；构造依赖源案例可恢复状态转移；描述性条件概率非因果；单次运行描述性统计。
