# FORGE: Self-Evolving Agent Memory With No Weight Updates via Population Broadcast (2026, ACM CAIS '26 / arXiv 2605.16233)

## 问题
LLM 智能体在随机、部分可观测的长时序环境（网络防御 POMDP）中零样本表现近乎灾难性；权重更新不可行时，孤立的 Reflexion 式单流反思缺乏选择压力，会累积反生产记忆且策略高方差。核心问题：该记什么（记忆表示）、记忆如何在种群中传播、梯度无关进化是否跨模型族可迁移。

## 方法要点（记忆/进化/修复机制）
- 分层 ReAct 智能体（Planner/Analyst/ActionChooser），记忆按角色持久注入 system prompt，容量固定。
- 内循环：失败触发的 Reflexion——单步奖励低于阈值 τ=-1.1 即中止 episode，由同底座 LLM 的 Reflector/Exemplifier 把失败轨迹转译为知识工件：Rules（条件启发式）/Examples（结构化示范）/Mixed。
- 外循环 FORGE 协议：N=10 并行实例、S=6 阶段；每阶段后冻结 checkpoint 评估，冠军实例的记忆整体广播替换其余活跃实例（PBT 从权重空间搬到 prompt 空间，广播为全量替换而非插值）；回报超过毕业阈值 θ=-15 的实例记忆冻结（防退化+省算力）。

## 实验与数据（benchmark+主指标）
- CybORG CAGE-2（B_line 攻击者，30 步 POMDP）。零样本→FORGE 平均回报：Gemini-2.5-Flash-Lite -189.6→-24.5（7.7×，Examples）、Qwen3-235B -103.3→-24.3（4.3×）、Llama-4-Maverick -113.1→-28.3（4.0×）、Grok-4-Fast -58.4→-33.7（1.7×，Rules）；单次最佳 checkpoint -3.60（DRL 榜首 -3.47）。
- 12/12 模型-表示条件下 FORGE 较孤立 Reflexion 提升 29-72%；重大失败（<-100）率从约 90% 降至约 1%。Rules 较 Examples 省 token 约 40%（106M vs 177M）。弱基线模型受益更大。无毕业消融证明冠军广播是关键机制。

## 创新点
1. 把 PBT 的 exploit/explore 映射为"冠军广播/失败反思"，实现免梯度的种群级记忆进化。
2. 受控比较三种记忆表示（Rules/Examples/Mixed）在对抗性 POMDP 下的回报-成本-可靠性。
3. 毕业机制（记忆冻结早停）分离出"广播=性能来源、毕业=算力节省"的因果结论。

## 与本选题关系（撞车风险：中）
同样是"冻结基座+记忆进化+失败驱动修复"的核心近邻：其失败触发的轨迹→工件转译即经验修复，冠军广播即跨实例策略进化；但差异在：纯文本网络防御域、无多模态、无记忆错误定位粒度（整库替换而非局部修复）——本选题的"证据驱动错误定位+局部修补"正可作为其整库广播机制的精细化替代。
