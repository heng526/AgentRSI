# WorldMemArena: Evaluating Multimodal Agent Memory Through Action-World Interaction (2026, arXiv 2605.29341 v2, UCSB)

## 问题与动机
- 多模态 LLM 正在变成长程 agent，记忆须不止于召回：要追踪演化世界、修订过时内容、在决策时给出正确证据。现有基准三缺陷：(i) 围绕长对话/长上下文，测"记住什么"而非"如何用过去经验指导未来行动"；(ii) 只报最终 QA 准确率，无法定位失败发生在写入/维护/检索/使用哪一环；(iii) 文本中心、图像降为 caption，多模态证据使用压力不足。
- Agent harness（OpenClaw、Codex）让 agent 自主编写与重组记忆，模糊记忆模块与策略边界——提出 Bitter Lesson 式之问：记忆应被评测为预定义 write-update-retrieve 管线，还是通过交互形成的能力？

## 方法拆解（基准框架）
- **形式化（Action-World Interaction Loop）**：o_t=Ω(z_t)，a_t=π(o_t,m_t)，(z_{t+1},f_t)=E(z_t,a_t)；轨迹按会话切分 τ=τ^(1)∘…∘τ^(S)，世界状态跨会话持续演化，后续决策依赖已不可见的证据→考记忆恢复与使用。
- **四阶段生命周期诊断**：Write（能否从当前会话识别未来有用的证据，选择性保留而非全存）；Maintain（新信息如何整合，支持修订与固化——"长期交互非纯追加"）；Retrieve（超越语义相似、要求决策相关）；Use（检索到的记忆是否被忠实用于回答/行动，失败模式含忽略相关证据、依赖过时记忆）。
- **数据构成**：461 个多会话多模态长程任务，两 regime——Lifelong Evolution（跨会话演化的个人与任务状态：职业垂直域+全生命周期域）与 Agentic Execution（真实 agent 轨迹：库存/位置/任务阶段/成败信号由动作与反馈驱动变化）。标注：gold memory points（含 update flags、importance、被取代的 original memories）、updates、distractors、QA 证据链——支持阶段级失败定位。
- **评测对象三范式**：long-context agents（GPT-5.4-mini、DeepSeek-V4、Claude Haiku 4.5、Gemini 3 Flash、Qwen3.6-plus 等）、手工设计记忆系统（RAG 与外置记忆）、harness 记忆 agent（OpenClaw-DeepSeek V4、OpenClaw-GPT 5.4-nano）。指标含 memory 存储召回/写入质量/QA/retrieval（Recall@K、NDCG@K）/分题型。

## 数据与实验
- 规模：461 任务（对比表中 LoCoMo 1,986 QA/272 会话、LongMemEval 500/23,867 步、HaluMem 3,467 QA、Mem-Gallery、AMA-Bench、MemoryArena 等均不含全生命周期四维诊断或多模态）。
- 四大发现：(1) 更好的写入与存储不保证更好性能——多数系统存储召回与写入质量高，但 QA 时证据召回大幅下降；扩大检索范围不总提升答案质量（冗余/过时/无关证据）；(2) 多模态记忆仍是瓶颈：视觉观察被压缩为文本记忆丢失时空/程序细节，复杂视觉任务表现差；(3) 跨域不稳定，agentic 执行任务上退化（关键信息散布在动作/工具反馈/状态变化中，而检索到的记忆点被显式文本事实主导，工具反馈/失败动作/视觉细节常被遗漏）；(4) harness 记忆更灵活但昂贵且欠可靠、框架依赖。
- 关键诊断："当前系统只累积、极少修订或删除过时条目（Figure 4b）——记忆维护由 append-only 行为主导"。
- 11 类能力雷达：GPT-5.4/DeepSeek-V4 领先，Gemini 在 Temporal Reasoning 与 Visual Search 尤弱。

## 创新点
1. 首个把多模态 agent 记忆评测分解为 Write/Maintain/Retrieve/Use 四阶段、以 gold memory point+update flag+superseded original 标注实现失败定位的基准。
2. 纳入 harness 自管理记忆范式并与手工管线、长上下文三方对照——首组 head-to-head。
3. 明确提出"记忆应为支持修订、冲突消解、选择性遗忘的可变状态，应奖励状态一致性而非覆盖量"的评测立场。

## 局限
- 基准只诊断不修复：能定位"维护阶段失败"，但被评系统本身无修复机制，排行榜上没有"修复能力"专项任务（update 任务有，但无"发现错误→定位→修正→验证"闭环评测）。
- 规模 461 任务相对小；数据源依赖自动生成会话+校验器（质量验证靠 validators），真实世界分布覆盖有限。
- harness 记忆评测绑定特定框架（OpenClaw/Codex），框架依赖性本身是其承认的局限。
- 世界状态演化靠脚本化反馈，非开放环境。

## 与本选题关系
- **撞车风险：中（作为评测基础设施）**。
- **overlap**：①四阶段诊断框架正是我们"记忆错误定位"想要的输出空间——其标注（gold memory points、update flags、superseded originals、evidence chains）可直接用作我们错误定位模块的评测 ground truth；②其四发现（append-only 主导、存储≠性能、文本化丢视觉细节、agentic 轨迹退化）是我们方法必要性的实证依据；③Lifelong Evolution+Agentic Execution 双 regime 与我们"跨任务进化"评测意图一致。
- **difference_from_ours**：WorldMemArena 是诊断性 benchmark，不提供修复算法，也无"修复后验证"的闭环协议；无训练/进化维度（静态系统比较）。最优用法：把它作为我们的评测平台之一（引用其阶段级指标报告我们的定位与修复收益），同时在 related work 中区分"测得出阶段失败"（它）与"修得好失败"（我们）。
