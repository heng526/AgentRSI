# AutoMem: A Text-Gradient Recursive Self-Improvement Framework for Automated Memory Architectures Search (2026, arXiv 2608.14621)

## 问题与动机
长期记忆是 LLM agent 核心，但记忆设计是高度耦合的架构问题：编码什么、怎么存、怎么检索、怎么管理随任务和基座模型而异。作者把记忆分解为四模块 Encode/Store/Retrieve/Manage，构建离散搜索空间（5 编码器×5 存储×6 检索器×4 管理器），试点研究证明：(1) 强架构存在但任务特定（GAIA 最佳随机架构 69.7% 超最强固定基线 MemoryBank 67.8%；xBench 46.0% 超已发表 SOTA 45.0%）；(2) 模块效应耦合非可加（强检索器救不了差编码器）；(3) 随机搜索能撞到 SOTA 但浪费预算、失败试验不产生可复用信号。

## 方法拆解
- **问题形式化**：任务自适应记忆架构选择——在可行空间 A（Valid(·) 过滤不兼容组合，valid-by-construction）中在评估预算 T 内最大化准确率，同时报告记忆诱导增益 Δ(a;B)=Acc(A_a)−Acc(A_0)（相对无记忆基座）。不更新基座参数、不合成任意记忆实现。
- **进化闭环（RSI 框架）**：两组件驱动的"提议→评估→诊断→验证"循环：① Experience-Guided Architecture Search——从历史搜索轨迹、已评架构、性能记录、累积反思中提出候选架构；② **Failure-Guided Module Diagnosis——把失败 rollout 定位到具体模块（Encode/Store/Retrieve/Manage），转化为定向文本反馈（text gradient）**指导下一轮架构编辑。这是本框架与我们的"错误定位→局部修复"最同构的部分：诊断在模块级归因，编辑是受控的模块级替换。
- **训练方式**：无参数训练；冻结两个任务骨干（Qwen3.5-122B-A10B、gpt-5.1-mini）。

## 数据与实验
GAIA / WebWalkerQA / xBench-DeepSearch × 2 骨干。Qwen3.5-122B-A10B：GAIA 71.5%（最强基线 +3.7）、xBench 46.0%（+1.0）、WebWalkerQA 72.5%（+3.6）；gpt-5.1-mini：分别 +1.9/+5.0/+1.8。效率：Qwen 下比最强准确率基线省 14.3% token；GAIA 上 No-Memory 基线 65.0%，随机搜索 10 个采样多数低于基线、最佳 69.7，AutoMem 单调升至 71.5 且用更少评估次数超越随机最佳。手工基线高度任务敏感（MemoryBank 强 xBench 弱 WebWalkerQA；Agent-KB 在 GAIA 低于 No-Memory）。发现的架构各模块组合随任务/骨干而异。

## 创新点
1. 首个把记忆系统本身当作 RSI 优化对象的可归因框架（对照 MemEvolve 的整体合成——无法给单模块记功、无法做受控模块级编辑）；2. 失败引导的模块级诊断+文本梯度反馈（把"失败归因"从终点接到"架构修复"闭环）；3. valid-by-construction 搜索空间保证候选可执行；4. 四模块分解表把 Generative Agents/MemGPT/Mem0/A-MEM/Zep 等统一为同一空间的固定点。

## 局限
架构空间是离散菜单组合（600 种组合级别），不能合成新机制；文本 QA/搜索任务，无多模态记忆内容本身（优化的是记忆架构不是记忆内容）；诊断由 LLM 完成、无严格归因验证；搜索用 held-out batch，任务分布漂移下架构可能需重搜；随机对照只 10 个样本。

## 与本选题关系
撞车风险：**中高**（方法论核心同构）。
overlap：其 RSI 循环=「失败 rollout→模块级错误定位→定向文本反馈→受控局部编辑→验证」，正是我们"证据驱动的错误定位+局部修复"在**记忆架构层**的版本；冻结基座设定一致；同样强调"不能只看任务分，要归因到模块"。MemoEvolve/Recuris 类工作被其引为对照，与本池已有 Recuris/KARMA 笔记可互相印证。
difference_from_ours：它修复的是**记忆架构（模块配置）**而非**记忆内容（错误条目/事实）**；对象是文本 agent 无多模态；错误定位基于 LLM 对 rollout 的分析而非多模态证据链。撞车风险点：如果我们的"修复"被表述为"调整记忆系统结构"，会被 AutoMem 覆盖——我们的差异化必须钉在(a)多模态/视频记忆内容级修复（定位错误事实、修订具体条目），(b)证据链驱动的定位（视觉-文本对齐证据而非 LLM 自由文本归因），(c)跨任务策略进化与内容修复的双层闭环。
