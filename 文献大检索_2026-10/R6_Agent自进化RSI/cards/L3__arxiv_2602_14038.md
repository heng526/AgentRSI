# Choosing How to Remember: Adaptive Memory Structures for LLM Agents (FluxMem) (2026, arXiv)

## 问题
两个盲区：(1) 记忆系统假设单一结构（graph/linear/hierarchical 之一）适配所有交互；(2) 结构选择从未被当作可优化的上下文自适应决策，与下游响应质量脱钩。另：固定相似度阈值做记忆融合在分布变化下脆弱。

## 方法要点（记忆/进化/修复机制）
- 三层记忆：STIM（4 页 LRU 短时缓冲）→ MTEM（情景单元库，至多 2000 会话，效用分 U(s)=w1 访问频率+w2 交互强度+w3 时效 淘汰/晋升）→ LTSM（≤100 条资格制剪枝的长期语义知识）。
- 多结构情景记忆：每个情景单元按内容被指派 linear/graph/hierarchical 之一；轻量 MLP 选择器（12 维交互特征）离线用交互衍生奖励（λ_q·judge 分 + λ_m·记忆利用率）自标注最优结构后做监督分类。
- Beta Mixture Model 概率门：相似度分数建模为双 Beta 混合（EM 估计），以后验 P(z=1|x) 取代固定阈值决定新记忆是否并入现有情景单元（阈值 0.6、min-keep 防过度过滤）。
- 冻结基座（GPT-4.1）。

## 实验与数据（benchmark+主指标）
- PERSONAMEM：FluxMem 平均准确率 72.43%，超最强基线 +9.18%（如偏好演化追踪 91.92、偏好对齐推荐 82.46）。
- LoCoMo：平均 F1 51.16/BLEU-1 41.73/ROUGE-L 49.51，较最优基线 +6.84 F1（多跳 48.56、单跳 62.12）。
- 消融：去 graph 结构 PERSONAMEM -7.0（Recall user facts 78.29）、去 linear -4.7、去 BMM -3.9；LoCoMo 上去 BMM 多跳 F1 -7.4、开放域 -16（BLEU）。

## 创新点
把"记忆组织结构本身"变成按对话内容在线选择的决策变量并用交互衍生奖励离线监督；BMM 分布级融合门替代手工相似度阈值，是记忆写入决策的统计化升级。
