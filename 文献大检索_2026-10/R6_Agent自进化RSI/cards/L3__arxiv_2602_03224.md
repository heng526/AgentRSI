# TAME: A Trustworthy Test-Time Evolution of Agent Memory with Systematic Benchmarking (2026, arXiv)

## 问题
测试时记忆进化（冻结参数、经验积累）只以任务成功率为唯一更新信号，导致 Agent Memory Misevolution：良性任务流中能力上升而可信度（安全/鲁棒/真实/隐私/公平）漂移下滑——部署期 reward hacking 的记忆版。

## 方法要点（记忆/进化/修复机制）
- Trust-Memevo 基准：Math/Science/Code/Tool-use 四域双轨（进化集 + 可信度评测集，数据源自 TrustLLM/ASSEBench/TruthfulQA 等，规模 946/700/385/298 条）。
- TAME：共享策略记忆库，每条记忆 m=(q, 经验 e, 历史有用性 Q∈[0,1], 信任标注 ψ)。
- Executor–Evaluator 循环：Executor 按语义相似度+Q 检索经验并把信任标注一并注入执行上下文；Evaluator 事后对每条被用记忆评贡献分 c_i∈[0,1]（记忆级信用分配：成功时评正贡献、失败时评估错贡献）。
- 进化更新：Q_{t+1}=Q_t+α·c_i·(r_task−Q_t)（α=0.2）——"错误记忆"通过贡献归因被降权而非删除；新经验按 Constitutional AI 原则生成信任标注后入库（Q 初值 0.5）。

## 实验与数据（benchmark+主指标）
- 骨干 Qwen3-32B 与 GPT-5.2；流式进化仅用二元对错反馈；结果为 3 次运行平均。
- GPT-5.2 AIME：TAME 0.733（ReasoningBank 0.587，+14.6pp）；Qwen3-32B GPQA 0.600、MMLU-Pro 0.902 均 TAME 最优。
- 可信度：Qwen3-32B Code 域 TAME 0.522 vs ReasoningBank 0.395（ReasoningBank+Guard 0.769 但牺牲任务分）；Science 域 TAME 0.816-0.824 稳定领先标准进化方法。
- 消融：去记忆归因（MA）MMLU-Pro 0.888→0.878、进化后可信度 0.817→0.793。

## 创新点
首次联合评测"测试时记忆进化×多维可信度"；把记忆进化从"结果驱动的追加"改为"贡献归因驱动的复用值校准"，每条记忆带信任标注实现谨慎复用——本质是一种证据（贡献归因）驱动的记忆质量控制机制。
