# Gödel Forest: Balancing Search Depth and Breadth for Data-Centric Recursive Self-Improvement (2026, arXiv 2609.36675)

## 问题与动机
RSI 两路线：多数优化冻结基座外的 harness/prompt；**data-centric RSI** 直接用 agent 生成数据训练更新模型参数。数据演化导航爆炸性组合空间（样本合成→数据集级分布偏移），且每个候选假设的验证要跑完整"数据生成→训练→评测"回路（training-in-the-loop 瓶颈）——由此产生深度-广度困境：单 agent 树搜索陷入路径依赖窄方向缺广度；朴素并行或重 trace 共享牺牲长程搜索深度（MGM 式多轨迹对比在同一任务上交换原始轨迹，上下文饱和、无法扩展到开放式数据发现）。核心问题：如何在昂贵训练验证下兼顾长程假设深挖与广泛方向探索。

## 方法拆解
- **形式化**：经验 Gödel 搜索=档案树搜索（每个节点是数据工程程序 a：Generate 合成 D_a→Train(θ0;D_a,λ_a) 训练候选模型→Eval 下游效用）；递归性在"早期候选模型的经验证据更新 agent 持久状态→支配后续数据生成"。
- **持久树搜索（局部深度）**：K 个 worker 各维护私有搜索树+证据台账，四阶段认知循环——Diagnose（分析失败模式：runaway completion/ungrounded actions/skipped verification，定位候选模型行为缺陷）→Propose（选父节点生成可执行数据合成/策展代码后继）→Validate & Evaluate（先在 worker 自主确定的小诊断子集 B_diag 上筛查，过门槛才评其余任务，早停剪枝不可行候选）→Review（深挖/调参/回溯祖先）。
- **共享进化记忆（全局广度+轻协调）**：read-evolve-publish 协议——worker 检索与自身证据相关的共享 lessons（Read）；条件化提议（含全局 leaderboard Λ_t）；把成败蒸馏为紧凑程序性 lessons 锚定全局排行榜发布（Publish）。死胡同瞬间成为全森林的归纳护栏，突破迅速播种到邻树。
- **训练方式**：目标模型参数被更新（每候选从固定 θ0 训练）；worker LLM（Claude Code+Sonnet-5 / Codex）固定。

## 数据与实验
RSIBench-Data 六域：SWE-bench Verified/Multilingual/Pro、Terminal-Bench 2.0、GPQA Diamond、AIME 2026。Claude Code+Sonnet-5（K=3）：平均绝对增益 +10.70%，SWE-bench Verified 35.00%→54.00%（+19.00）最显著；六任务中五个端到端 wall-clock 时间缩短（异步并行+负发现快速传播剪枝）。跨骨干：Codex worker 下 SWE-bench Verified 33.00%→44.00%（+11.00）、Terminal-Bench 2.0 20.22%→23.60%（+3.38）。消融：共享进化记忆协同比独立并行搜索 +7.00%；并发规模与深度-广度权衡分析；微观案例两 lessons（Stopping Boundary Guardrail、Supervising Verification Actions）展示跨 worker 知识合成。

## 创新点
1. 首个 data-centric RSI 的多智能体协同搜索框架（把 RSI 组织为共进化搜索树 ensemble）；2. 异步 read-evolve-publish 共享记忆替代原始 trace 交换（紧凑 lessons+全局排行榜锚定）；3. 诊断子集筛查门控缓解 training-in-the-loop 成本；4. 私有树（深度）×共享记忆（广度）的结构化对偶。

## 局限
每个候选仍需真实训练（成本仍高：SWE-V vanilla $181.70）；蒸馏 lessons 由 LLM 自由文本生成、无错误定位到数据项级别；无多模态；评测全量基准仍然昂贵（诊断集阈值需调）；复杂度随 K 与任务增长。

## 与本选题关系
撞车风险：**低-中**（改权重的数据侧 RSI，与外置记忆正交）。
overlap：其"失败教训蒸馏为紧凑 lessons+全局排行榜+跨 worker 传播"与我们"跨任务策略进化"的记忆层同构；"死胡同=全森林护栏"是负面记忆复用的范例；multi-tree 并行探索与我们修复策略搜索的广度设计相关。
difference_from_ours：目标模型权重被更新（每候选重训），与冻结基座设定相反；改进对象是数据合成策略而非记忆内容；无多模态感知记忆。引用价值：作为"RSI 光谱另一端（data/weight-centric）"的代表作，用于在 related work 中界定我们"冻结基座+外置记忆进化"的定位；其 lessons 蒸馏+负证据传播设计可启发我们跨任务修复策略库的组织。
