# SYNAPSE: Empowering LLM Agents with Episodic-Semantic Memory via Spreading Activation (2026, arXiv)

## 问题
标准 RAG 的"搜索假设"（相关性=与 query 的语义邻近）导致 Contextual Isolation：因果/传递相关的记忆（如数周前的日程冲突）与 query 无词汇或嵌入重叠时无法被召回。

## 方法要点（记忆/进化/修复机制）
- 统一情景-语义图：情景节点（逐轮交互+嵌入+时间戳）+语义节点（每 5 轮 LLM 抽取概念，嵌入相似 0.92 去重）；边分时间边/抽象边/关联边；Top-15 入边剪枝 + 低激活节点 10 窗口后归档，控制图规模 ≤10k。
- 扩散激活检索（ACT-R）：BM25+稠密双触发注入能量 → 带 fan effect 的传播（S=0.8、时间衰减 ρ=0.01）→ 侧抑制（top-7 竞争抑制）→ sigmoid 激活，T=3 轮收敛。
- Triple Hybrid 打分：λ1·语义相似 + λ2·激活值 + λ3·PageRank（全局结构先验）。
- 不确定性拒答："Feeling of Knowing"门控（top-1 激活能 < 0.12 即拒答）+ 严格证据验证提示，对抗性幻觉拒答 F1 96.6，非对抗类误拒率 <2.5%。
- 记忆维护靠时间衰减与垃圾回收（被动遗忘），无主动条目修复。

## 实验与数据（benchmark+主指标）
- LoCoMo（长对话均值 16K tokens、最多 35 sessions），GPT-4o-mini 统一 backbone 复跑基线。
- 加权平均 F1 40.5（SOTA，+7.2 over A-Mem 33.3；Zep 39.7、AriGraph 33.7），任务平均排名 1.0；Multi-Hop F1 35.7（A-Mem 27.0，+23% 相对提升）；时间推理 F1 50.1；Adversarial F1 96.6（次优 69.2）。
- 效率：每 query 约 814 tokens（较全上下文 16,910 降 95%）、延迟 1.9s、$0.24/1k queries，F1/$=167.3。
- 消融：去 node decay 时间 F1 50.1→14.2；去 fan effect 开放域 25.9→16.8；纯向量基线平均仅 25.2。

## 创新点
把检索从"相似度搜索"改为图上的能量传播动力学（扩散激活+侧抑制+fan effect），解决语义不重叠的因果桥接召回；激活能兼作校准的拒答置信信号。
