# Audited Skill-Graph Self-Improvement (ASG-SI) via Verifiable Rewards, Experience Synthesis, and Continual Memory (2025, arXiv, cs.CR)

## 问题
部署中的自改进智能体面临运营安全难题：优化压力+分布漂移+不完美可观测性导致 reward hacking、脆弱特化、不可追溯的行为漂移。核心问题：自我改进的"改进单元"是什么，如何被验证、复现与治理。

## 方法要点（记忆/进化/修复机制）
- 把自我改进重构为"把智能体迭代编译进一个不断增长的有向技能图"：节点=带显式前置/后置条件接口的技能，边=组合约束/依赖顺序/带守卫的回退。
- 技能编译器从成功轨迹提取可复用子序列并规范化为 canonical 程序；verifier–auditor 在受控 harness 中重放候选技能/组合，产出"最小充分证据包"（schema 校验日志、确定性测试结果、制品哈希、验证器版本），只有通过证据门控的技能才被提升入技能图。
- 可分解奖励（工具有效性/结果验证/技能复用/组合完整性/记忆纪律）全部可从证据包重建，支持渐进式 shaping；失败可在技能图节点/边级别定位（failure localization）。
- 经验合成（参照 DreamGym）用于压力测试技能接口与边界条件，并周期性用真实 rollout 重新锚定；持续记忆控制惩罚无界上下文增长，verified skill 持久化为回退单元以抗遗忘。

## 实验与数据（benchmark+主指标）
无基准实验数字——本文为设计/立场型工作，附 GitHub 最小可运行原型（asg_si_demo.py：确定性验证环境、工具注册表、append-only 审计 trace、奖励分解日志），第 13 节给出评估计划（能力增长按直接推理/技能复用/组合归因分解；SWE-Bench-CL 式任务流测留存；约束遵从与 reward-hacking 审计；audited improvement rate 复合指标）。

## 创新点
把"证据包"作为自我改进的一等公民：提升决策与奖励构造绑定到可重放、防篡改（哈希+版本化）的制品上，使技能级失败定位与第三方审计成为可能；从安全治理视角切入 RSI。

## 与本选题关系
撞车风险：中低。同样主张"证据驱动的改进门控与失败定位"，但 ASG-SI 的证据用于技能（代码工件）提升与 RL 奖励审计，面向安全治理，且无实验验证、无多模态、不做记忆条目内容级的错误定位与修复；可作为"证据驱动修复可审计性"论述的引用支撑。
