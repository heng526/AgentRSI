# MIRIX: Multi-Agent Memory System for LLM-Based Agents (2025, arXiv 2507.07957, MIRIX AI/UCSD/NYU)

## 问题
现有记忆系统三大缺陷：扁平单一存储缺乏按记忆类型路由的组合结构；文本中心、多模态（图像/屏幕）支持差；原始输入（尤其图像）存储不可扩展且无抽象层。

## 方法要点（记忆/进化/修复机制）
- 六类结构化记忆：Core（persona/human 块，超 90% 容量触发受控重写）、Episodic（时间戳事件+摘要/详情/参与者字段）、Semantic（概念/实体知识，概念覆盖式更新）、Procedural（工作流/指南/脚本）、Resource Memory（文档/多模态文件）、Knowledge Vault（需逐字保留的敏感信息，带敏感级与访问控制）。
- 多智能体工作流：Meta Memory Manager 路由 + 六个 Memory Manager 并行维护各自记忆类型（更新时去重）；Chat Agent 执行"主动检索"——先由模型生成 topic，再从六类记忆各取 top-10 注入系统提示，免显式触发；支持 embedding/BM25/string 多检索工具。
- 记忆修复相关：用户纠错查询可由 Chat Agent 直连对应 Memory Manager 做精确更新；Core 重写与语义记忆"概念覆盖"是内置的轻量修正机制。

## 实验与数据（benchmark+主指标）
- ScreenshotVQA（新基准，3 名博士生 5349-18178 张高分辨率屏幕截图/序列，87 题，gemini-2.5-flash 骨干）：MIRIX 59.5%（0.5455/0.5667/0.6727），较 SigLIP RAG 基线（44.1%）高 35%（相对），较 Gemini 长上下文基线（11.7%）高 410%；存储 15.89MB vs SigLIP 15.07GB（-99.9%）。
- LOCOMO（gpt-4.1-mini 骨干，3 次运行均值）：总体 85.4%，超最佳已有方法 8.0%。

## 创新点
1. 六类记忆+Meta 路由的多智能体记忆架构（8 智能体分工）。
2. 面向屏幕截图流的多模态记忆基准 ScreenshotVQA 与极致压缩存储。
3. 主动检索（topic 生成驱动）消除显式记忆查询需求。

## 与本选题关系（撞车风险：低）
多模态记忆系统的工程代表作（六类记忆+路由），但更新机制为路由入库+去重，无证据驱动的错误定位、无修复闭环、无策略进化；LOCOMO/ScreenshotVQA 可作本选题候选评测参考。
