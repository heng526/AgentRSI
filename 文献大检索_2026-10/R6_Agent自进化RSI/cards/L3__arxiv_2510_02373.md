# A-MemGuard: A Proactive Defense Framework for LLM-Based Agent Memory (2025, arXiv 2510.02373, NTU)

## 问题
记忆投毒的两个特性使防御困难：(1) 恶意记录孤立审计无害、只在特定上下文触发危害（ASB 显示先进 LLM 检测器漏检 66% 的投毒条目）；(2) 触发后形成自强化错误循环——被污染结果作为先例入库，放大初始错误并降低后续攻击门槛。

## 方法要点（记忆/进化/修复机制）
- 非侵入式外部验证层 V(qt, Mr)，两大机制：
  1) 共识验证：对每条检索记忆 mi 生成自由推理理由再抽取结构化推理路径 ρ̂_i（实体-关系语义轨迹），K 条并行路径计算分歧分数 S_div，超阈值 τ 者判异常并从净化集 M_val 中剔除——用记忆间一致性暴露上下文依赖的恶意条目。
  2) 双记忆结构+自学纠正：异常路径本身作为结构化"负教训"存入独立 lesson memory；执行前把候选计划结构化为路径，检索结构相似教训，命中即触发审议循环强制修订计划——错误转为防御资产，阻断错误循环。
- 三种 S_div 实例：LLM 直接判定（主方法）、嵌入距离、DBSCAN 聚类。

## 实验与数据（benchmark+主指标）
- 直接投毒（AgentPoison，ReAct-StrategyQA + EHRAgent，GPT-4o-mini/LLaMA-3.1-8B，DPR/REALM）：EHRAgent 检索层 ASR-r 从 100.0 降至 2.13；ReAct-StrategyQA ASR-r 37.50→0.00（LLaMA-3-8B）；总体 ASR 削减 >95%（EHRAgent 场景 >97%），良性任务准确率保持最高。
- 间接注入（MINJA 式，MMLU）：ASR 降低 >60%，多轮模拟中近零错误传播。
- 多智能体（MISINFOTASK，错误信息注入）：任务成功率 0.950 为全部方法最高。

## 创新点
1. 首个智能体记忆的主动防御框架（共识机制+从自身错误学习）。
2. 以结构化推理路径分歧做上下文相关异常检测，替代孤立条目审计。
3. 负教训记忆库（异常路径=防御性经验），把安全机制与经验学习统一。

## 与本选题关系（撞车风险：中低）
其"检测异常记忆→转成教训→指导未来行为"与"错误定位→局部修复→策略进化"在机制骨架上同构，但目标函数是安全性（ASR）而非任务能力进化，错误来源是外部投毒而非自产经验噪声；lesson memory 只增不改主记忆（被污染记录仅被绕过、未被修复）。可引为"记忆错误检测与隔离"的近邻，本选题强调修复主记忆本身与任务能力增益。
