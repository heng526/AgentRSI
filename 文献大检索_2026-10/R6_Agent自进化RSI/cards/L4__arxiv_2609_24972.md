# RRSI: Regularized Recursive Self-Improvement of Agent Harnesses (2026, arXiv 2609.24972)

## 问题与动机
harness（冻结基座外层的 prompts/控制流/工具/记忆/上下文管理）决定 agent 能力上限，近期方法用 LLM 迭代提议+选择组件级编辑实现 agent 系统层 RSI。但递归演化会**过拟合**：在有限 evolve 集上反复自适应采样，带内收益大、OOD 上缩水甚至消失。三种耦合的过拟合行为：benchmark-specific fitting（编码基准特有模式）、noise chasing（被评测噪声抬举的候选转正）、complexity accumulation（复杂度累积涨分不涨机制）。核心问题：RSI 的泛化——演化出的 harness 迁移到任务描述/工具接口/验证器都不同的未见基准。

## 方法拆解
把 ML 正则化原则翻译成自适应 harness 搜索的约束（编辑空间保持全开：prompts/控制流/配置/上下文/工具/技能/记忆/子代理都可改，正则化的是搜索轨迹）：
- **提议侧**：① L0 式退火更新稀疏性——每候选可捆绑的"可独立归因编辑数"预算 b_t 按 cos 调度从 b_max 退火到 b_min（早期允许组合变更发现新机制、后期稀疏可归因）；② 证据感知 credit assignment——记录每候选的组件/假设/diff/分数与成本变化/是否接受，被拒机制成为负证据，成功机制保留显式功劳；③ 结构化探索——进度 w 轮内停在噪声带 δ 内视为 stall，留一小部分预算给未使用过的组件（熵正则类比）。
- **选择侧（非补偿性准则）**：① 泄漏筛查——critic 在评估前读 diff，拒绝编码任务名/实体名/任务特定值/答案或惰性机械的编辑（防泄漏候选拿到虚高带内分）；② 稳定性感知接受——演化前反复评基座估噪声带 δ，候选须过噪声调整地板 Ŝ≥S*−δ（防"逐步小幅退化被当噪声"）；③ L2 式复杂度感知接受——ΔS>δ 时须 ΔC≤β0+β1ΔS（策略 token 成本增长须由分数增长辩护）；④ L1 式结构剪枝——剪枝窗内无严格正增益的组件被上报为删除目标（机制必须持续"挣得"其位置）。
- **训练方式**：完全冻结策略（Claude Opus 4.8 / Gemini 3.5 Flash 双策略验证），proposer/analyst/critic 均 Claude Opus 4.8；基座 harness Terminus-2（编码）/ReAct+MCP 工具网关/动态工具带。

## 数据与实验
8 基准 3 域：编码（Terminal-Bench 2.1 演化 + SWE-bench Verified OOD）、agentic workspace（Harvey LAB 120 演化+40 held-out + JobBench/GDPval/APEX-Agents OOD）、工程设计（EngDesign 演化 + Frontier-Eng OOD）。Claude Opus 4.8：演化集 +6.0（TB2.1）/+4.9（EngDesign）/+1.1（Harvey）；held-out 全部六分割不回退：SWE-V +1.8、Harvey held-out +2.3、三个 OOD agentic +3.5~4.7（相对 7.2–13.1%）、Frontier-Eng +4.3 Medal（相对 +24.3%）；Gemini 3.5 Flash 下 TB2.1 演化 +14.1、SWE-V +2.2（跨策略鲁棒）。效率：比未正则化演化省 30% policy tokens；超基线方法平均最高 22.9%。消融验证各正则件贡献（agentic workspace OOD 平均）。

## 创新点
1. 首次把 harness RSI 的过拟合显式化为研究问题并给出正则化框架（L0 编辑预算/L1 剪枝/L2 成本收缩的经典对应）；2. 泄漏筛查前置到评估前（防泄漏候选获得吸引后轮的虚高分）；3. 噪声带估计+噪声调整地板防止噪声追逐；4. 证明"演化集收益"与"迁移收益"解耦——六个 held-out 分割全部不回退。

## 局限
文本任务域（终端/法律工作区/工程设计），无多模态；单域演化单集（每域一个演化集）；正则超参（δ/β/窗口）需在演化集上调；成本代理仅 policy tokens；LLM critic/leakage 筛查自身可能有漏。

## 与本选题关系
撞车风险：**中高**（其"防过拟合的正则化"问题与我们的修复泛化问题同构）。
overlap：我们做"记忆错误修复"同样面临过拟合——修复可能记住特定失败案例而非获得可复用修复策略；RRSI 的四件套（编辑稀疏预算/证据感知 credit/噪声地板/成本-收益约束）可直接移植为我们修复策略进化的正则化设计；泄漏筛查对应我们"不得把特定视频内容答案写进修复"。
difference_from_ours：优化对象是 harness 源码/提示而非记忆内容；无多模态；无错误定位环节（正则化选择而非诊断）。引用价值：(a) 为我们修复闭环的"泛化 vs 记忆化"评测设计（演化/评估分割+OOD 基准+不回退检查）提供模板；(b) 其 30% token 节省与 22.9% 超基线数字说明正则化在 RSI 中收益显著，支撑我们把正则化纳入修复准入的必要性论证。
