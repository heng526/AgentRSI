# Agentic Memory (AgeMem): Learning Unified Long-Term and Short-Term Memory Management for LLM Agents (2026, arXiv)

## 问题
现有方法把长时记忆（LTM）与短时记忆（STM）当作独立模块，靠启发式规则或外挂记忆管理器，难以端到端优化且依赖额外专家 LLM。

## 方法要点（记忆/进化/修复机制）
- 把 6 个记忆操作作为工具动作并入策略动作空间：LTM 侧 Add/Update/Delete（条目级修改与删除即"记忆修复"原语），STM 侧 Retrieve/Summary/Filter。
- 三阶段渐进课程 RL：Stage1 休闲对话中学 LTM 存储 → Stage2 重置上下文、注入干扰消息学 STM 过滤/压缩 → Stage3 端到端协调双记忆解题；阶段间保留 LTM、重置 STM 防泄漏。
- Step-wise GRPO：终端奖励组归一化后广播到全轨迹各步，解决记忆操作导致的稀疏/不连续奖励的长程信用分配。
- 复合奖励 R_task（LLM judge）+ R_context（压缩效率/预防性动作/信息保全）+ R_memory（存储质量/维护(更新删除)/语义相关）+ 溢出惩罚。

## 实验与数据（benchmark+主指标）
- 5 个 benchmark：ALFWorld/SciWorld/PDDL/BabyAI/HotpotQA；基座 Qwen2.5-7B-Instruct 与 Qwen3-4B-Instruct（仅 HotpotQA 训练后零样本迁移）。
- Qwen2.5-7B 平均 41.96%（Mem0 37.14、A-Mem 36.78、noRL 33.43）；Qwen3-4B 平均 54.31%；较最优基线 +4.82/+8.57 pp，RL 带来 +8.53/+8.72 pp。
- 记忆质量 MQ（HotpotQA 与 ground-truth 事实相关性）：0.533/0.605 均为最高；prompt tokens 较 RAG 变体降 3.1%/5.1%；奖励消融 All-Returns J=0.544/MQ=0.533 vs Answer-Only 0.509/0.479。

## 创新点
首次把 LTM+STM 管理统一为单一可学习策略（异构记忆动作同策略端到端 RL），三阶段课程+step-wise GRPO 解决记忆操作碎片化轨迹的训练难题；Update/Delete 作为学到的"记忆纠错"行为被 RL 显式激励（维护奖励）。

## 与本选题关系
撞车风险：中高。"Update/Delete 错误记忆"与本选题的记忆局部修复高度相关。差异：AgeMem 靠 RL 微调模型权重（非冻结基座）、无证据驱动的错误定位（何时该改哪条全靠策略隐式学）、纯文本无多模态；可作为"记忆维护作为可学习动作"的强基线与引证。
