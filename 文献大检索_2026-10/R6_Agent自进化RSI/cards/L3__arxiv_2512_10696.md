# Remember Me, Refine Me (ReMe): A Dynamic Procedural Memory Framework for Experience-Driven Agent Evolution (2025, arXiv 2512.10696, SJTU/Tongyi Lab)

## 问题
现有程序记忆框架陷入"被动积累"范式：静态 append-only 档案。三大缺陷：轨迹级粗粒度经验引入无关信息；检索经验不加适配直接套用；缺乏及时更新导致经验池退化为有效洞察+有毒噪声的混合体。

## 方法要点（记忆/进化/修复机制）
- 结构化经验单元 E=⟨场景 ω, 内容 e, 关键词 κ, 置信度 c, 工具 τ⟩。
- 多面蒸馏：总结 LLM 对成功/失败轨迹做成功模式识别、失败诱因分析、成功-失败对比洞察三路提炼；LLM-as-a-Judge 验证可用性；余弦相似度去重；按使用场景 ω 的嵌入索引入库。
- 上下文自适应复用：场景索引检索 top-K → LLM 重排 → 改写模块把多条经验重组为任务定制指导。
- 效用驱动精炼（记忆池的"新陈代谢"）：选择性添加（仅成功轨迹实时蒸馏入库——单条失败轨迹上下文不足易产生误导经验）；失败感知反思（失败→总结教训→带教训重试，最多 3 次，成功才入库）；效用删除——记录每条经验的检索次数 f 与历史效用 u，f≥α 且 u/f≤β 即删除（引用了 error propagation 实证研究作为动机）。

## 实验与数据（benchmark+主指标）
- BFCL-V3 与 AppWorld，Avg@4/Pass@4。Qwen3-8B：No Memory BFCL 40.33/59.55、AppWorld 14.97/32.85 → ReMe (dynamic) BFCL 45.17/68.00、AppWorld（fixed）17.06/36.31；超过 A-Mem 与 LangMem 基线。记忆缩放效应：Qwen3-8B+ReMe 超过无记忆 Qwen3-14B，Avg@4 平均 +8.83%、Pass@4 +7.29%。发布 reme.library 细粒度程序记忆数据集。

## 创新点
1. 程序记忆全生命周期闭环（蒸馏-复用-精炼）替代被动积累。
2. 成功-失败对比蒸馏与失败感知反思重试（失败先转化为探索再决定是否入库）。
3. 效用衰减删除机制与"记忆质量替代模型规模"的实证结论。

## 与本选题关系（撞车风险：中高）
同为冻结 LLM+程序记忆+失败驱动进化+效用化维护，问题设定高度重合。差异：ReMe 的"精炼"是记录级的添加/删除+复述改写，不做条目内错误定位与定向修补（错误的经验只能整体删除），无多模态、无记忆内容级证据链。本选题必须引用并以"更细粒度的错误定位+修复（而非删除）+多模态证据"划界。
