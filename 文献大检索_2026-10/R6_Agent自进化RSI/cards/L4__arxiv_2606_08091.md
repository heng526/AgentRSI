# VideoWeaver: Evaluating and Evolving Skills for Agentic Long Video Generation (2026, arXiv 2606.08091, 浙江大学+字节跳动)

## 问题与动机
- 通用 agent harness（Claude Code/Codex/OpenClaw）擅长工具使用与编排，但能否胜任长视频生成这种长程多模态任务未被系统研究；现有视频 agent（Mora/StoryAgent/UniVA/Co-Director）编排管线人工固定。
- 评测难题：错误可发生在生成过程任一环节（计划缺陷/工具调用失败/中间产物损坏），仅评最终视频会漏诊过程性失败——现有视频生成基准（VBench/Video-Bench 等 11 个）全部只测 output，最多 UniVA-Bench 有 3 个过程指标。

## 方法拆解
- **任务设定**：单条指令→长视频。harness 中骨干 LLM 只具备文本推理能力，配一组 foundation skills（视频/图像/音频的生成、理解与媒体处理，自包含可独立调用）；agent 自行把 foundation skills 组合为 composition skill（高层程序化工作流）并执行；skill-creator 是"从 foundation skills+任务样例构造 composition skill"的技能。
- **Agent-as-Judge（证据接地评测）**：Claude Code+DeepSeek V4 配评测技能——动态调工具检查执行轨迹、抽视频元数据、采关键帧、分离音轨、跑 ASR、错误分析、视/音频内容理解；对 6 个过程指标（EE 执行无错率/CM 剪辑合并/IP 输入处理/PL 规划/SF 技能遵循/RAU 参考资产使用）与 7 个输出指标（FR 格式/PR 内容/VC 视觉一致性/AC 音频一致性/AVC 音画同步/PLC 剧情逻辑/RF 参考保真）各给 {0,1} 分+证据+置信+文本反馈；强调跨剪辑一致性。人类评测：3 名标注者（普通用户/AI 视频研究者/电影学专家）对 n 个候选排序打分。
- **技能进化算法（三阶段）**：执行 agent A_exec 任务推理生成初始类目级 composition skills 并收集轨迹/输出/评测反馈→优化 agent A_opt 用反馈渐进精炼 composition skills 与 creator skills→合并 agent A_merge 把多个 creator skills 合并为单一 C*。默认分工：OpenClaw+Seed2.0 执行、CodeX+GPT-5.5 优化、Claude Code+DeepSeek V4 评测（三个不同 harness-model 对缓解自偏好偏差）。
- **训练方式**：全 prompt 层，无参数训练；技能以文本工件形式进化（冻结一切模型）。

## 数据与实验
- 基准：16 任务类、285 案例；参考材料跨文本/图像/音频/视频及组合；训练/测试均衡划分+3 个 OOD 类目。专家人工构建各类目 composition skill 作参考基线。
- 主结果（Table 4，OpenClaw+Seed2.0 执行）：No Composition Skill RGT 38.29/VC-RGT 0.80 → Composition Skill 48.81/0.78 → Self-Evolution 61.78/0.73/工具调用 46.98 → Evolution with Feedback RGT 56.08 但输出指标均值更高——自进化已捕获轨迹可见的程序性修复，判官反馈主要贡献"agent 无法从自身轨迹自评"的输出质量信号。专家 composition skill 输出均值最佳（人工编排仍是最强参照）。
- 跨 harness+模型：Codex+GPT-5.5 Ranking Score 4.90 > Claude Code+Opus 4.7 4.64 > Claude Code+DeepSeek V4 4.45——性能显著依赖 harness 与模型选择。
- 泛化：测试类目上优化后 composition skill 胜 25.3%/负 16.5%；OOD 类目优化后 creator 胜 23.8%/负 16.5%——编排经验可迁移非过拟合。
- 人评对齐：200 案例 judge vs 3 标注者，过程指标上对齐尤其好（Kendall 相关）。

## 创新点
1. 首个面向通用 agent harness 的长视频生成基准与"证据接地的 agent-as-judge"（过程 6+输出 7 指标，检查轨迹+中间工件而非只看成片）。
2. 三 agent 分工的技能进化管线（执行/优化/评测分离+creator skill 合并），证明"评测反馈→技能文本精炼→跨类目迁移"闭环可行。
3. 用三个不同 harness-model 对互评以抑制自偏好偏差的实验设计。

## 局限
- 仅数百案例（约 1 分钟视频生成与评测成本高）；foundation skills 依赖字节系生态。
- 作者自认：需更原则性的优化方法、**执行轨迹上更好的 credit assignment**、更强的技能验证——即"哪步轨迹证据该为哪个技能缺陷负责"尚未解决，进化靠优化 agent 整体读反馈。
- 技能进化是文本工件级粗粒度更新，无错误定位到具体技能片段的机制，无回归测试（技能更新可能破坏已有能力，仅靠胜率粗验）。
- 面向视频生成，不涉及视频理解记忆。

## 与本选题关系
- **撞车风险：低-中（任务域不同）**。
- **overlap**：①"轨迹+中间产物作为证据、agent-as-judge 逐指标定位过程失败"与我们的证据驱动错误定位思想同族（可视为文本级先例）；②"评测反馈→技能/策略工件精炼→合并→OOD 迁移"正是跨任务策略进化的视频域实例；③其 limitation 明示 credit assignment 与技能验证是 open problem——恰是我们定位模块的用武之地。
- **difference_from_ours**：对象是视频生成编排技能而非视频理解记忆；进化单位是整段工作流文本而非记忆条目/策略项；无记忆读写机制；错误反馈来自 judge 评分而非任务成败归因。可引用其 limitation 论证"轨迹级 credit assignment 是未解问题"，并作为"策略进化在视频域的另一任务面"的对照工作。
