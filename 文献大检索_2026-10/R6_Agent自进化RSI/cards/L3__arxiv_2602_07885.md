# MemCoRe: Recovering Evidence from Progressively Compressed Factual Knowledge for Agent Memory (2026, arXiv)

## 问题
压缩-可检索性权衡（信息瓶颈式形式化）：保留全部内容则证据被冗余条目淹没——诊断实验显示 A-MEM 在 LoCoMo 上即使保留几乎全部原始信息，仍有近半 ground-truth 证据无法被检索到（top-20 召回 53.8%，28.2% 检索结果为近重复）；压缩过猛又会丢弃日后相关的证据。失败随查询类型系统变化（开放域/多跳最差）。

## 方法要点（记忆/进化/修复机制）
- 压缩层级记忆：notes（原始内容 r_t + 去噪上下文 c_t + 嵌入 + 关键词 K_t）→ keywords（实体级中间层，共现图）→ topic groups（Leiden 模块度聚类，大小约束 3-15）。
- 门控构造（gated construction）：LLM 评估新观察与候选条目的语义关系，三选一——Merge（冗余→合并上下文保留双方原始内容）、Link（互补→建关联边，关系类型 Supports/Conflicts/Related_To + 强度 s∈[0,1]，高强度时部分信息转移更新邻居上下文）、Append（新颖→新条目）。
- 三通路检索：topic 质心匹配 + keyword 实体匹配（RRF 融合）+ 邻居扩展（沿关联边 1 跳、强度调制）+ 迭代证据精化 IER（LLM 判覆盖缺口→合成子查询→重检索，I_max=3）。
- IB 目标改造：L(M_t)=I(X;M_t)−β·I(M_t,Q;T)，把"检索目标由查询共同决定"显式建模；Neo4j 图存储，Qwen3-Embedding-0.6B。

## 实验与数据（benchmark+主指标）
- LoCoMo，四个骨干（GPT-4o-mini/4o、Qwen3-8B/14B），对比 7 个基线。
- 平均 F1 全部四个骨干最高：GPT-4o-mini 43.76（超 A-MEM +1.79）；GPT-4o 44.39；Qwen3-8B 38.62（超 LightMem +3.53）；Qwen3-14B 33.65。
- 检索召回 62.22%（A-MEM 诊断值 53.8%）；消融（Qwen3-8B）：去全部门控构造 F1 38.62→27.97（-10.65，最重）、Recall 62.22→42.11；去 Link 33.57 < 去 Merge 34.79（关系结构比去冗余更重要）；去 IER Recall 62.22→46.29；去 Keyword 32.69（单跳最受伤）。

## 创新点
用信息瓶颈给"压缩 vs 可检索"权衡以形式化词汇；Merge/Link/Append 门控是证据级的记忆整合（含 Conflicts 关系显式标注）——把"冲突检测"写入记忆构造；IER 迭代精化把多证据查询的检索做成闭环。

## 与本选题关系
撞车风险：中。Link 中的 Conflicts 关系与门控整合已是"写入时记忆一致性处理"，但冲突仅作边标注、不做证据驱动的错误定位与旧条目改写修复；纯文本。其 IB 形式化与"诊断→设计"的论证结构对本选题方法学叙述有参考价值。
