# ICM-Bench: Person-Level Identity Reasoning in Multimodal Agents with Long-Term Memory (2026, arXiv 2609.04438)

## 问题与动机
长程多模态 agent 需要身份中心的关系记忆：把重复出现的脸、声音、名字、关联物件、事件、社会关系绑定到稳定身份并跨时间推理（"提醒我她上周答应了什么"这类指令无法绕开身份消解）。现有多视频/多模态记忆基准测"发生了什么/证据在哪"，重复人物身份只是附带——聚合 QA 分数无法区分"靠稳定身份推理答题"还是"靠局部事件/转写/共现线索答题"。

## 方法拆解
- **激励性诊断**：先在 M3-Bench Web 子集（100 视频 575 题）对 M3-Agent 做消融——去掉人脸处理反而 52.5%→55.3%，关掉脸-声等价链接 53.0%，纯音频 52.2%：宽泛 QA 分数基本不依赖身份机制（很多题靠转写/局部事件/共现即可答对），证明需要身份中心的新基准。
- **基准构建**：主题可配置生成管线（系列 bible→shot 计划→身份一致性锚点检查→Veo 渲染 4/6 秒 720p→角色 TTS 声音→人工审核去身份漂移/快捷方式）。实例化"李明的一年生活相册"：839 clips/141 分钟/6 个重复出现的成人/44 场景组；1,217 个开放题（400 Identity Recall/500 Cross-Episode Identity Retrieval/317 Long-Term Identity Profile Inference），每题带可追溯证据锚（clips/shots）、目标身份、时间截止 τ。三家族分别测：事件挂到正确人/跨分离 clip 的同身份链接/重复证据聚合成稳定人级 profile。
- **评测**：开放作答+共享 Gemini 3 Flash 语义等价 judge（与两套独立人标 95.3–96.6% 一致）。不规定记忆架构。

## 数据与实验
人类 93.8%（Profile 89.6%）。最佳自动系统 Gemini 3.1 Pro 直推字幕记忆 Overall 74.0% 但 Profile 仅 60.3%（人与机器 Profile 差 29.3 点）；Gemini 3.5 Flash 73.4%（Profile 50.8）。记忆 agent/图检索在开源模型上总体提升但 Profile 下降：Qwen3.5-9B Profile 44.2%（直推）→31.2%（Vgent）→27.4%（HippoRAG2）；Qwen3-VL-8B 43.2%→32.8%/42.0%。M3-Agent（Qwen2.5-Omni-7B SFT）45.4%，去等价链接 42.9%、去人脸 41.0%——在身份中心基准上身份组件的贡献可见（与宽泛基准上的反直觉消融对照）。ASR-only：Gemini 3.5 Flash 73.4%→38.7%，证明非转写视觉证据必需。定性失败三模式：关系性 profile 错认（把李明的摄影记忆答成王林的模式）、检索干扰物（答"旅行票据"而非反复出现的明信片）、重复证据下的过度弃答（HippoRAG2 说证据不足）。

## 创新点
1. 首个身份中心长视频记忆基准，问题按"证据必须围绕稳定人物组织"设计且带可追溯锚；2. 用 M3-Agent 消融实证"宽泛 QA 分数掩盖身份机制失灵"；3. 分离事件级记忆与人级 profile 聚合两种能力，发现"记忆组织改善事件检索反而损害 profile 推理"的 trade-off；4. 合成可控生成管线（可换主题复用）。

## 局限
纯合成视频（无遮挡/运动/光照/重叠语音等真实挑战），作者自认是受控诊断不能外推到真实录像；记忆架构不规定导致系统间差异混杂答案模型能力；开放题依赖单一 LLM judge（虽验证了与人标一致性）；无修复/更新评测轴（静态记忆）。

overlap：直接建立在 M3-Agent 之上并实证其身份链接机制的错误模式（Appendix H：把不同人的观察错误链接到同一身份）——这正是我们"多模态记忆错误定位"要修的那类**实体绑定错误**；Profile 推理失败三模式（关系错认/检索干扰/过度弃答）可为我们错误分类学提供视频域样例；记忆组织改善检索却损害聚合的 trade-off 提示修复机制要分能力轴评测。
