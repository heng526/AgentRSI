# Reinforcement Learning for Self-Improving Agent with Skill Library (2025, arXiv)

## 问题
LLM 智能体部署到新环境后难以持续自我改进；现有技能库方法（Voyager、Agent Workflow Memory、Agent Skill Induction 等）依赖 prompt 提示生成/使用技能，受基座模型指令遵循能力限制，技能生成与利用质量不稳定。

## 方法要点（记忆/进化/修复机制）
- SAGE（Skill Augmented GRPO for self-Evolution）：把技能库行为本身纳入 RL 训练目标，而非仅靠提示。
- 统一格式：沿用 DynaSaur 思路，任务求解与技能生成为同一动作空间——先生成技能函数再调用，而非直接调 API。
- Sequential Rollout：每次 rollout 是同场景相似任务链（长度 2），前序任务生成的技能累积进技能库供后续任务使用，使后续技能使用成功的奖励可回传给前序技能生成。
- Skill-integrated Reward：可验证结果奖励 + 技能奖励（成功任务的技能被后续任务成功使用 → 技能生成奖励；成功使用前序技能完成任务 → 技能使用奖励）；无代码直接终止罚 -1.0。
- 先用 Claude 3.5 Sonnet V2 专家轨迹 SFT（Qwen2.5-32B-Instruct），再做 SAGE RL（无 KL 惩罚，组内均值去基线）。

## 实验与数据（benchmark+主指标）
- AppWorld（750 任务/250 场景，9 应用 457 API），基座 Qwen2.5-32B-Instruct。
- Test-Normal：SAGE 72.0% TGC / 60.7% SGC，平均 12.1 步、1,475 tokens；对比无技能库 GRPO 69.2% / 51.8%、16.4 步、3,613 tokens（SGC +8.9%，步数 -26%，tokens -59%）。
- Test-Challenge：SAGE 50.1% TGC / 32.4% SGC，超 LOOP（45.7/26.6）与 GRPO（40.7/26.9）。
- 技能使用成功率较 SFT/基座提升 2 倍以上；消融：技能整合奖励优于 Outcome-based（55.4 SGC）与 Chain-based（56.6 SGC）；3 任务链（54.8 SGC）反而不如 2 任务链；检索消融中 Query N-gram（60.1 SGC）接近同场景理想设置（60.7）。

## 创新点
首次把"技能生成+技能使用"作为可验证奖励直接端到端 RL 训练，使技能库自进化行为成为模型内化能力；Sequential Rollout 用任务链结构解决技能质量的跨任务信用分配。

## 与本选题关系
撞车风险：中。同属"跨任务策略/技能进化"，但 SAGE 通过 RL 更新模型权重（非冻结基座），且无证据驱动的记忆错误定位与局部修复机制；其 Sequential Rollout 与技能奖励设计可为冻结基座下技能记忆进化的训练端参照。
