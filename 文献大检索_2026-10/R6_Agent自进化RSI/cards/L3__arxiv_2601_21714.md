# E-mem: Multi-Agent Based Episodic Context Reconstruction for LLM Agent Memory (2026, arXiv)

## 问题
主流记忆预处理范式（嵌入/图/层级压缩）造成"破坏性去上下文化"（destructive de-contextualization）：把复杂序列依赖压缩进刚性结构，切断深度推理所需的上下文完整性，难以重建因果链。

## 方法要点（记忆/进化/修复机制）
- 印记（engram）式保留：滑动窗口（8K、带 overlap）切分原始未压缩情景上下文，每个片段由一个小语言模型助手智能体（Qwen3-4B）作为独立记忆单元持有，平时休眠归档。
- 三通路路由激活：全局摘要对齐 + 原文语义向量 + BM25 符号实体触发，任一通路命中即激活（Multi-Source Activation Union），O(1) 流式增量更新。
- 情景上下文重构：被激活的助手在完整原生上下文内"重新经历"并局部推理，产出带绝对时间戳 τ 的证据元组 e=<c,τ>；master 智能体聚合时按时间戳优先最近信息解决状态冲突（如位置变化的过时事实）——以推理时序消解代替记忆条目修改。
- 支持 Iterative Refine-and-Query 多步推理；冻结基座（无训练）。

## 实验与数据（benchmark+主指标）
- LoCoMo：GPT-4o-mini 主模型下 Overall F1 54.17（超 SOTA GAM 45.31 达 +8.86；多跳 42.64、时间 59.82）；Qwen2.5-14B 下 57.04（多跳 49.15）。平均超最强基线 +7.75% F1，token 成本降 70%+。
- HotpotQA 流式（400/800/1600 文档，>200K tokens）：E-mem 61.46/55.46/55.76 F1 均最高（1600 文档较 RAG +6.51%）。
- LoCoMo 对抗子集 F1 峰值 95.74（Qwen3-8B 助手）；成本：归一化成本约 3.6k 单位（1:10 大小模型 token 比），较全上下文 169k 降 43 倍；消融：chunk=8K 最优（4K 噪声、32K lost-in-middle）；去全局对齐路由 F1 55.76→45.30；去助手直读管线 38.27。

## 创新点
反"压缩预处理"之道而行：用多智能体持有未压缩原始情景、按需激活重构上下文，证据带时间戳供聚合端做冲突消解；以小模型并行局部推理换大模型上下文成本。

## 与本选题关系
撞车风险：中。处理"过时/矛盾记忆"的方式是查询时用时间戳消解而非修改记忆库，属"检索端对抗错误记忆"，与本选题"库内错误定位+局部修复"互补；其"证据必须带时间戳"的设计对证据驱动修复有直接借鉴价值。纯文本、无进化机制。
