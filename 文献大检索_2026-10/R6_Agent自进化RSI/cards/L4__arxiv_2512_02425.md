# WorldMM: Dynamic Multimodal Memory Agent for Long Video Reasoning (2025, arXiv 2512.02425, KAIST/NTU/DeepAuto.ai)

## 问题与动机
- 视频 LLM 在小时/天级长视频上受上下文限制、抽象化丢失视觉细节；已有 memory-based 方法（M3-Agent、EgoRAG、HippoMM）过度依赖文本表征，推理时无法利用视觉证据。
- 两个具体缺陷：(1) 检索与生成时不自适应选择模态——固定"文本+帧"配对策略会让无关视觉帧干扰推理；(2) 固定时间尺度的片段检索（如固定取 3 个 30s 片段）无法覆盖跨度差异巨大的事件（几秒 vs 半场球赛）。

## 方法拆解
- **Agent 架构**：三阶段——多模态记忆构建 → 自适应检索 agent → 响应 agent。检索 agent 迭代式输出（memory, query）对或 STOP 信号（最多 N=5 轮），基于用户问题与检索历史决定访问哪种记忆、用什么查询。
- **记忆读写机制**：三种互补记忆。
  - Episodic memory：多时间尺度文本知识图集合 M_e={G_t0..G_tN}（如 EgoLifeQA 用 30s/3min/10min/1h 四个尺度），每尺度分segment→caption→实体-动作-实体三元组建图；
  - Semantic memory：持续演化 KG，按固定粗粒度 ts 分段提取语义三元组，用 embedding 相似度（阈值 0.6）找出重叠/冲突三元组，交由 LLM 判定 T_remove / T_update，执行 Consolidate(G∖T_remove)∪T_update——这是一个"记忆图的增量冲突消解写机制"；
  - Visual memory：双通道——segment 级多模态 embedding 特征库 M_v^f + 帧-时间戳索引 M_v^I，支持关键词检索与时间戳直取。
- **进化或修复闭环**：无训练/无参数更新。唯一"演化"成分是 semantic memory 的增量 consolidation（检测冲突→LLM 裁决→删除/修订写入），属推理期记忆维护，不是自我改进闭环。
- **训练方式**：全部 zero-shot 调用（GPT-5-mini 建记忆；GPT-5 与 Qwen3-VL-8B-Instruct 作检索/响应 agent，对应 WorldMM-GPT / WorldMM-8B）。

## 数据与实验
- 5 个长视频 QA benchmark：EgoLifeQA（周级）、Ego-R1 Bench（周级）、HippoVlog、LVBench、Video-MME；指标为多选题 accuracy。
- 主结果：WorldMM-GPT 平均 69.5%，超最强基线 8.4%；对比同为 GPT 骨干的 HippoRAG 57.0%、HippoMM 51.8%；长视频 LLM 类基线在 EgoLifeQA/Ego-R1 全部低于 50%。
- 消融：E+S+V 比 E+S 平均 +4.2%；HabitInsight 上全记忆 76.9%，比去掉 semantic memory（E+V）+23%；EntityRecall 类别超 Ego-R1 11.2%。
- 多轮检索：EgoLifeQA 允许 5 步比单步检索 +9.3%；episodic 用固定单时间尺度 -6.1%、用 embedding 替代图 -4.4%；semantic 去掉 consolidation 约 -7%（长时推理类目）；visual 关掉双模式检索约 -3%。
- 效率：100 条 EgoLifeQA 抽样查询测端到端 latency，latency-accuracy 权衡优于长视频 LLM 与 RAG 基线。

## 创新点
1. 首次在长视频记忆 agent 中将"记忆模态选择"（text KG vs visual frame）本身作为检索 agent 的动作空间，避免强制配对加载无关模态。
2. 多时间尺度 episodic 图 + 查询驱动的动态时间范围检索（DTSR），替代固定片段长度。
3. Semantic memory 的 embedding 召回 + LLM 裁决的冲突感知增量写协议。

## 局限
- 完全冻结模型、无参数学习与经验积累：记忆每条视频从头构建，不跨任务复用；无错误定位/修复概念——检索失败只靠再迭代。
- Semantic consolidation 只处理相似度>0.6 的三元组，冲突裁决靠单次 LLM 判断，无验证机制。
- 阈值与时间尺度需按数据集手工设定（数据集特定 timescales）；记忆构建成本（GPT-5-mini 逐段 caption + 建图）未详细核算。
- 实验全为多选题 accuracy，缺开放生成与具身任务验证。

## 与本选题关系
- **撞车风险：中**。
- **overlap**：同为 M3-Agent 系视频记忆架构谱系（直接以 M3-Agent 为图1对照对象），同样做长视频多模态记忆的"写入-组织-检索"管线，semantic memory 的冲突检测-修订写机制与我们的"记忆错误定位→局部修复"在写入口处有概念相邻性。
- **difference_from_ours**：WorldMM 是纯推理期静态管线——无证据驱动的错误定位、无对错误记忆的回溯修复、更无跨任务策略进化；其"演化"仅限单视频内 semantic 图的增量合并，不跨任务、不积累可复用策略。可作为本选题的直接 baseline 与"记忆写入端冲突消解"引用点，但不构成对"冻结基座下的记忆错误定位与修复闭环"的占位。
