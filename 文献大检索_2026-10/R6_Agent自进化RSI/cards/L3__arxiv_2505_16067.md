# How Memory Management Impacts LLM Agents: An Empirical Study of Experience-Following Behavior (2025, arXiv 2505.16067, Harvard/MSU/UGA)

## 问题
记忆库的动态演化（添加/删除操作）如何影响 LLM 智能体长期性能缺乏原理性理解：记忆库中含智能体自产的噪声轨迹，无差别添加与随意删除可能通过检索传播错误。

## 方法要点（记忆/进化/修复机制）
- 发现"经验跟随"（experience-following）性质：当前查询与检索记录的输入相似度高→输出相似度也高（RegAgent 中 Pearson r≈1），即智能体倾向模仿检索到的经验。
- 由此识别两大失效：错误传播（错误经验被检索→复制→再入库→放大）；错位经验重放（看似正确的记录作为示范持续导致劣化执行）。
- 管理对策：轨迹评估器把关的选择性添加（coarse 自动评估器 C1/C2/C3 与 strict 人工/真值评估）；删除侧提出 history-based deletion——记录被检索≥n 次且历次检索的平均下游效用≤β 即删除（未来任务评估作为记忆的"免费质量标签"）；另有周期删除与联合删除。
- 挑战场景：任务分布漂移与记忆容量受限下的管理。

## 实验与数据（benchmark+主指标）
- 4 个智能体（合成 RegAgent、EHRAgent、AgentDriver、CIC-IoT，GPT-4o-mini 为主）：RegAgent 成功率 fixed 67.53 / add-all 55.48 / C3 67.35 / strict 70.95；EHRAgent 准确率 fixed 16.75 → strict 38.50；AgentDriver 成功率 40.11 → 51.00；CIC-IoT 71.50 → 85.40。add-all 记忆膨胀至 2125-4100 条且性能低于固定记忆基线。
- 删除实验：配 strict 评估器时 history-based 在真实智能体上最佳（EHRAgent 33.55 vs 无删除 25.91）；联合删除内存压缩最大（EHRAgent 338 条 vs 1447）。仅 300 条轨迹微调的评估器（C3）即带来显著长期提升。

## 创新点
1. 首次系统量化"经验跟随"性质及其带来的错误传播/错位重放两难。
2. 证明评估器质量（而非记忆数量）是长期自改进的关键；无差别添加比固定记忆更差。
3. 以未来任务效用为免费质量信号的历史删除策略。

## 与本选题关系（撞车风险：中高）
与本选题"证据驱动记忆错误定位"的问题意识高度重叠：错误经验必须被识别和清除是共同前提。但本文停留在"记录级整条添加/删除+评估器选择"的实证研究，未做错误内容定位、不修复（只删不改）、无多模态、无策略进化——本选题的"定位-局部修复"恰是其指出的 error propagation 问题的更细粒度解法。需在相关工作中重点引用并区分粒度。
