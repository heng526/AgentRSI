# Task-Focused Memorization for Multimodal Agents (TaskMem) (2026, arXiv 2605.31075, ByteDance Seed + 复旦)

## 问题与动机
- 长期记忆的核心挑战是"记什么"（what to memorize）：具身多模态 agent 面对无界多模态观测流，须从组合爆炸中选择性保留对自身角色与未来任务有价值的内容（关联 AI Frame Problem）。
- 现有工作把记忆内容生成当作与任务执行并行的独立过程，内容生成仍靠 prompt 工程或预定义模板后训练，显式优化"该记什么"的工作缺失——记忆形成本身可能与环境真实任务需求错位。
- 主张：记忆不是被动存储而是主动的、目标驱动的过程；把记忆生成建模为可学习的"记忆化策略"（memorization policy）。

## 方法拆解
- **形式化**：滑窗上下文 q_t=(v_{t-k+1:t}, m_{t-k+1:t-1})，策略 π_θ(m_t|q_t) 决定每段视频的 episodic 记忆；轨迹级奖励置于末 token，最大化 E[r(τ)]。身份处理：把全局 face ID 框注在画面上+ASR 转写以 speaker ID 字幕形式叠加进视频输入本身（而非附加长工具输出文本），缩短上下文且保身份推理。
- **Phase One（部署前，学 how to memorize）**：GSPO（组序列策略优化）从零 RL 训练记忆生成——多目标奖励 r_fmt（格式）+r_len（推理长度软惩罚）+r_qual（准确/非冗余/风格，奖励模型评）+r_rich（组内相对 richness 排名转标量，防"准确但空洞"的奖励劫持）。理由：SFT 受合成数据质量封顶且最大似然不显式优化全局目标；评判（对齐/冗余检测）比生成容易，宜用 RL 把判别力转成生成力。只需原始视频，无需标注。
- **Phase Two（部署后，学 what to memorize）**：在线适应——用最近 n 个环境任务构造任务相关性奖励模型（先推断示例任务意图，再比较两候选记忆哪个更相关）；对 Phase One 策略的 rollout 预计算缓存，部署时高效构造成对偏好数据；DPO 优化。应对三挑战（反馈稀疏/灾难遗忘/算力）：只在基座 MLLM 单个 transformer 层加 2,048 参数的加性向量适配器 h_o←h_o+a，骨干全程冻结，π_ref=Phase One 策略。
- **训练方式**：Qwen3-VL-30B-A3B；Phase One 全参 GSPO RL，Phase Two 仅适配器 DPO（近冻结基座）。

## 数据与实验
- 评测协议：把 VideoMME/EgoLife/EgoTempo 重构为流式基准——按题型分组为任务环境（每个任务=一个环境），视频按序流入、逐段生成记忆，问题在视频处理完才揭示，且只能用记忆作答（不得回看原视频）→准确率直接反映记忆质量。指标 Acc/Cov/Prec。
- 主结果（Table 2）：TaskMem VideoMME Acc 67.9/Prec 85.6、EgoLife 45.4/80.5、EgoTempo 27.6/63.2；相对基座 Qwen3-VL-30B-A3B（61.6/38.4/22.3）分别 +6.3/+7.0/+5.3。对比 M3-Agent（62.5/21.8/16.0）、HippoMM、EgoGPT、Gemini-1.5/2.5-Pro（63.2/43.8/25.8）、GPT-5.2（67.3/34.8/32.1）：VideoMME 与 EgoLife 全面最优；EgoTempo Acc 略逊 GPT-5.2（32.1）但 Prec 更高（63.2 vs 62.4）=幻觉更少。
- Phase Two 训练动力学：任务相关性升、记忆质量保持稳定、适配器范数稳步增长。
- 消融：Phase One 与 Phase Two 各自贡献分解（Phase One 即已超基座）；更换 QA 生成器增益保持。

## 创新点
1. 首个把"记忆内容生成"本身作为可学习策略并用 RL 显式优化"记什么"的工作（区别于记忆模块/存储/固化/纠错的系统级设计）。
2. 两阶段设计：离线 RL 打记忆质量地基 + 部署后仅 2K 参数适配器的在线 DPO 任务对齐——近冻结基座下的测试时记忆策略适应，兼顾遗忘与算力。
3. 身份信息原位标注（face ID 框+speaker ID 字幕烧进视频输入）替代附加文本上下文。

## 局限
- 只做 episodic 记忆生成，作者自认 semantic/visual memory 与更交互的具身环境留作未来工作。
- "任务相关性"由近期 n 个任务定义，任务分布漂移时的适应滞后未讨论；无错误记忆的检测/修正（只优化写入内容的相关性，写入错误靠 r_qual 的事前预防）。
- 流式重构的基准仍以 QA 为终点，无动作执行闭环。
- Phase One 需要全参 GSPO RL 训练（成本高、奖励模型质量是上限）；Phase Two 适配器仅单层加性向量，表达能力受限。

## 与本选题关系
- **撞车风险：中低**。
- **overlap**：①同处 M3-Agent 谱系的长视频流式记忆赛道（直接以 M3-Agent/HippoMM 为基线、复用 EgoLife 基准——与我们池内 WorldMM/M3-Agent 对照面重叠）；②"用近期任务反馈在线调整记忆写入策略"与我们"跨任务策略进化"的输入信号一致；③其 2K 参数适配器+冻结骨干的 Phase Two 是"冻结基座下最小可训练面"的实例。
- **difference_from_ours**：TaskMem 优化的是"写入策略的相关性"（task-relevance of memorization），不是"记忆的错误定位与修复"——错误只靠事前质量奖励预防，无事后审计、无证据驱动归因、无修复写入；策略适应对象是单一记忆生成策略而非跨任务可复用策略库；评测是封闭式 VQA 而非智能体任务执行。引用定位：TaskMem 解决"记得对不对题"，我们解决"记得错怎么办"——互补且正交，可作为写入策略学习一脉的代表引用。
