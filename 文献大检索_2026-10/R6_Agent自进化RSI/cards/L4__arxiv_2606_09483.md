# Memory Beyond Recall: A Dual-Process Cognitive Memory System for Self-Evolving LLM Agents (DCPM) (2026, arXiv 2606.09483, 腾讯 LLM 部)

## 问题与动机
- 长期记忆不止于"恰时恰点召回正确段落"。现有系统把信念修订（belief revision）、因果耦合（causal coupling）、跨域抽象（cross-domain abstraction）全压进单一检索面，丢失了信念演化的中间状态、使远距查询可召回的因果链接、跨生活域复现的高阶图式——隐性个性化（推断用户如何演变）失败。
- 根因诊断：memory-as-storage 与 memory-as-cognition 混淆。以认知能力层级重组：原始输入+原子事实 → 身份项+信念的历时 supersedes 链 → 域内行为图式 schema 与潜在意图 intention → 跨域核心图式；理论根基为 Theory-of-Mind 发展与双过程理论（快在线编码 vs 慢离线抽象）。

## 方法拆解
- **架构（双过程共享存储）**：向量库存 raw inputs（先落盘零丢失）/facts/identity；独立图 G 存 schema 与 intention（两类平权节点）；每图节点带 evidence_vdb_ref 边回指支撑事实。
- **System 1（同步日间写者，按需触发非每轮）**：四步——(i) raw persist（任何 LLM 调用前先存原始输入，下游失败不丢内容）；(ii) 抽取 LLM M_e 一次调用产出 identity items+atomic facts（带 type/topic/salience/timestamp）；(iii) reconcile LLM M_r 对每个条目+top-k 近邻判定 ADD/SUPERSEDE/UPDATE（完全重复静默丢弃）；(iv) SUPERSEDE 时写双向指针 n_new.Supersedes=n_old、n_old.SupersededBy=n_new，**不删除前驱**——在平面向量库上形成修订的双链表，读时 O(k) 遍历恢复完整演化弧（含 embedding 相似度通常错过的"因果中段"）。
- **System 2（异步夜间引擎，数十秒预算）**：Phase 1 免 LLM 预处理（未入图事实分诊+两段 DBSCAN 聚类+质心双向检索图上下文）；Phase 2 归纳 agent M_a 每簇一次调用、四个工具（create_schema/create_intention/add_evidence/add_edge），动作按发射序持久化、图跨夜增量演化；Phase 3 跨域清扫器——LLM 把每个 schema 抽象为短行为描述嵌入行为空间 E_beh、句编码器得语义空间 E_sem，"行为相似但语义相远"（cos_E_beh>θ_beh 且 cos_E_sem<θ_sem）判为 collision，union-find 聚合后由 M_c 归纳出更高层 core schema 写回图。
- **训练方式**：无训练；抽取/调和用 deepseek-v4-flash 或 kimi-2.5（no-think，温度 0/0.6）；读路径纯确定性（向量库+指针+图遍历），读时零 LLM。

## 数据与实验
- 基准：LongMemEval(S)、PersonaMem(32k)、PersonaMem-v2(32k)，两组抽取/推理模型（deepseek-v4-flash/kimi-2.5）。
- 主结果（Table 1）：DCPM full kimi 下 PersonaMem 76.73 / LongMemEval(S) 86.14 / PersonaMem-v2 59.30；vs 长上下文 agent 77.59/80.61/58.46、Mem0 65.23/48.87/41.25（+graph 65.82/51.26/40.16）、Zep/Graphiti 64.21/62.35/38.27。**System 2 增益与架构预测一致**：在奖励隐性跨会话推理的 PersonaMem-v2 上最大（kimi +5.20：54.10→59.30），在 span recall 上几乎无贡献。DCPM lite（仅 S1）亦单独报告（如 kimi LongMemEval 85.81）。
- 阶段消融（PersonaMem-v2）：lite→full 的增益全部来自 schema/intention/core schema 层。
- 长上下文对照反例分析：为何 DCPM 在 LongMemEval kimi 上超长上下文 agent。
- 现状 plateau：公开报告的 LongMemEval 分题型显示表面召回型（user-fact/knowledge-update）近饱和，整合型（preference/multi-session/temporal）落后。
- **失败模式（自述）**：supersedes 链会"过火"——抽取/调和 LLM 把瞬时状态误判为稳定修订；θ_beh 对 benchmark 敏感。PersonaMem-v2 上 S1 平均每用户写 1.8 条 supersedes 链（0–7）。
- 成本：S1 每轮至多一次抽取+一次调和调用；S2 离线；读延迟与纯检索系统相同。

## 创新点
1. supersedes 双向链：不覆盖删除的修订历史保留机制——"信念如何演变"成为一等可查对象，且读路径零 LLM。
2. 跨域清扫器：行为空间相似+语义空间相远的双空间碰撞检测归纳 core schema，把跨域抽象变成可执行算子。
3. 认知能力层级把"现有系统都在被动基底层"变成可检验命题（S2 增益分布验证）。

## 局限
- 纯文本对话个性化域（LongMemEval/PersonaMem），无多模态/视频/具身。
- 无错误定位：SUPERSEDE 判定错误（把瞬时状态当稳定修订）被列为失败模式但无检测/撤销机制——supersedes 链一旦写错，链上没有纠错算子，只能等下一次 SUPERSEDE。
- 跨域抽象阈值 θ_beh benchmark 敏感；schema/intention 质量无显式验证。
- 跨任务维度止于"跨生活域"的模式归纳，非任务执行策略。

## 与本选题关系
- **撞车风险：中低**。
- **overlap**：①"信念修订轨迹可追溯（supersedes 链+不删前驱）"与我们的证据链/回滚友好记忆结构同向——修订历史保留是修复的前提基础设施；②双过程"快写慢改"分工与我们"在线修复 vs 离线审计"的调度一致；③其自述失败模式（瞬时状态误判为修订、无纠错）直接论证记忆错误定位-修复的必要性。
- **difference_from_ours**：DCPM 的演化是"追加式抽象"（schema/intention/core schema 只增），修复仅隐含在链式 SUPERSEDE 里且无验证；无任务反馈驱动的错误发现（个性化 QA 场景没有执行成败信号）；无多模态；无跨任务策略。引用定位：作为"修订可追溯记忆结构"的代表 + 用其失败模式段落支撑我们的动机；把"supersedes 链上无纠错算子"写为我们的差异点。
