# EvoMemBench: Benchmarking Agent Memory from a Self-Evolving Perspective (2026, arXiv 2605.18421 v2, HKUST-GZ/BUPT/BIT/Createlink)

## 问题与动机
- agent 记忆能力缺系统评测：LoCoMo/LongMemEval/MemoryAgentBench 只测知识保持/检索，不测执行；MemoryArena/Evo-Memory/StuLife/MemoryBench 靠近交互或跨 episode 但未同时覆盖 in-episode×cross-episode、knowledge×execution 四象限，且部分未开源。
- 核心视角：自进化记忆 = episode 内保留并修订演化知识、维护任务执行状态 + episode 间积累可复用知识、蒸馏执行经验。

## 方法拆解（基准设计）
- **两轴四象限**：memory scope（in-episode：任务级紧凑状态 / cross-episode：经验级紧凑状态）× memory content（knowledge：保持+修订冲突信息 / execution：动作相关状态+可复用程序经验）。
- 形式化：m_{t+1}^e=U(m_t^e,o_t^e,a_t^e,y_t^e)，动作条件于 a~π(·|h,o,m)。
- **六数据集**：InEp-Know（MemoryAgentBench 的 Accurate Retrieval 2000+Selective Forgetting 800）；InEp-Exec（BFCL-Multiturn-LongContext 重构：显式实体→隐式指代强迫从记忆恢复、多动作轮拆分；GPT-5-mini 辅助重构+人工校验）；CrossEp-Know（CL-Bench 重构为 120 contexts/884 samples，按 DeepSeek-V3.2 分数三分为 Easy/Medium/Hard，四知识形态：领域事实/规则系统/程序/经验模式）；CrossEp-Tool（BFCL-Multiturn-Base 同法重构）；CrossEp-Web（xbench-DeepSearch 100 + WebWalkerQA 170）；CrossEp-Emb（ALFWorld 6 类 200）。
- **评测协议**：统一 backbone DeepSeek-V3.2 + 15 种记忆方法五类（检索：BM25/Qwen3-Emb-4B/GraphRAG；短期：MemAgent/MemoBrain；通用长期：Mem0/A-MEM/MemOS/MemoryOS；程序性长期：AWM/SkillWeaver/AgentKB/ACE/ReasoningBank；元进化：MemEvolve）；memory-free 基线 Gemini-3-Flash/GPT-5-mini/DeepSeek-V3.2。指标：accuracy（知识）、success rate（执行）、token usage。

## 数据与实验（八条 finding）
- F1 长上下文基线极强：Gemini-3-Flash 在 retention 与 revision 均最佳 rank——上下文够时保原始证据比外置记忆抽象更可靠。
- F2 **记忆方法"善存不善改"**：BM25/Mem0/A-MEM 在 retention 子集超 no-memory 基线，但 FactConsolidation（多跳）急剧下降——瓶颈不是检索而是"当新证据与旧记忆冲突时，决定更新/抑制/替换哪条存储信息"。
- F3 上下文预算受限时记忆更有用（InEp-Exec 16K-128K 扫描）。
- F4 执行任务受益于程序性指导，但压缩有风险（丢细粒度执行细节）。
- F5 记忆帮难伤易：Easy 上 memory-free 52.1 vs 最好记忆方法 50.0（通用长期记忆仅 43.8–46.8）；Hard 上 DeepSeek-V3.2 0.0，ACE 提至 13.0、BM25 10.1、MemoryOS 9.0。
- F6 瓶颈在"形成可复用知识"而非"存更多"：ACE 在 medium/hard 全面最佳（16.5/13.0），规则系统应用 easy/medium/hard 74.9/24.0/7.8——记忆应支持知识如何被应用。
- F7 执行域偏好不同记忆形态：Tool Using 检索类最佳（平均 rank 5.43）、Web Search 通用长期最佳（5.38）、Embodied 程序性长期最佳（5.60）——没有万能记忆形态。
- F8 跨环境迁移取决于记忆是否匹配目标决策过程：tool-use 迁移稳定为正（决策步骤相似：查中间态→用输出选下一调用→验终态）；ALFWorld 子环境差异大，迁移易变中性/负。

## 创新点
1. 首个按 in/cross-episode × knowledge/execution 四象限统一自进化记忆评测的开放基准（Table 1 显示唯一四象限全覆盖+开源）。
2. "retention vs revision"与"帮难伤易"的实证刻画，直接给出记忆修订（conflict 决定更新哪条）是核心瓶颈的证据。
3. "记忆形态×任务决策过程匹配度决定迁移收益"的结论，为跨任务策略进化设计提供评测依据。

## 局限
- 纯文本/符号任务（工具、网页、ALFWorld 符号化具身），无视频/多模态记忆评测。
- 记忆质量维度单一（任务成功率），不评错误记忆的检测/修复；无记忆内容级诊断指标。
- 六数据集多为重构/采样子集，规模有限；Hard split 上基线 0.0 的绝对值过低，区分度依赖少数方法。
- 静态骨干、无训练侧适应；元进化仅 MemEvolve 一个代表。

## 与本选题关系
- **撞车风险：低（基准）**。
- **overlap**：F2"善存不善改/修订是瓶颈"是我们"记忆错误定位与修复"最直接的基准级证据，应在动机部分引用；CrossEp-Exec 四数据集+迁移结论为我们"跨任务策略进化"的评测提供现成协议；其 finding 8 的"记忆须匹配目标决策过程"呼应我们策略沉淀时的任务对齐问题。
- **difference_from_ours**：不覆盖多模态/视频记忆，不评"错误记忆被发现与修复"的过程性指标（只评端到端成败），无诊断式记忆审计。可用作我们实验的补充评测或引用其协议设计（统一 backbone+五类方法对照），并明确指出其四象限中缺少"多模态×修复型演化"格。
