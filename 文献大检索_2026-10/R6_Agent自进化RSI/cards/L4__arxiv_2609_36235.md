# MERID: Multimodal Exploration via Recursive Self-Improvement Agents for Major Depression Analysis (2026, arXiv 2609.36235)

## 问题与动机
重度抑郁检测依赖多模态数据（访谈录像、语音、面部行为、传感器），各模态时间分辨率与特征结构差异大，需要定制的预处理/融合/预测管线；管线设计本质是迭代实验。现有工作三层自动化（手工架构/LLM agent 建管线/agent 自设计），但都难以做到：**基于实验反馈自主修订管线，并把验证过的改进继承到后续设计**。三个 RSI 特有难题：❶ 经验可靠性——记录组织方式变化会改变 subject-target 对应，扭曲候选比较与后续反馈；❷ 耦合修改目标——表示/融合/预测器交互，固定伴随组件会掩盖协调变更的收益；❸ 继承不确定性——小样本抑郁队列上重复选择会青睐采样波动而非真实改进。

## 方法拆解
- **框架（经验驱动 RSI 循环）**：状态 S_t=(checked 适配器 A_D, 候选空间 Q_t, 现任管线 I_t, 修订历史 L_t, **research memory K_t**——历史记录 outcomes，memory 存可修订的、链接证据的 lessons）；Improver(提议)→Verifier(固定协议 Π+指标 μ 验证+更新经验)→Inherit(继承决策)。
- **GSC（接地状态构造）**：共享检查型数据适配器保证跨 recipe 的 subject-target-record 对应不变（Id(A(r))=Id(A(r′))）；首个有效输出建立固定参考排序与目标分配；执行检查验证形状/有限值/对齐，recipe 探针检测被忽略的配置；失败触发修复后才能留用。
- **CPE（耦合管线探索）**：把完整管线 θ=(r 表示-融合 recipe, c 预测器配置) 作为改进目标，候选空间 Q=R×C 组合新提出与保留组件，共享协议评估。
- **EGE（证据引导进化）**：反馈引导修订；**不确定性缩放的接受裕度**——基于 subject 级分数不确定性验证管线替换（防止小样本噪声继承）；理论给出保留裕度界（retention-margin bound）。案例：MPDD-2025 Elder 候选 0.4569 vs 现任 0.4178，增益低于 0.0470 接受裕度被拒→审查后加 ordinal 模型与树深设置，64 次评估后最佳开发分 0.4814（测试分不变）。
- **训练方式**：LLM 权重/角色定义/评估协议在 run 内固定（改的是管线代码/配置，非模型权重）。

## 数据与实验
基准：E-DAIC、MPDD-2025/2026、Mental Health Multimodal、Kaggle TESS/RAVDESS。vs MulT/Flex-MoE/MCMoE/MDAgents/Direct LLM：E-DAIC PHQ-8 CCC 0.3268/0.3201（两配置）vs 最佳基线 MDAgents 0.0520；MPDD-2026 Young PHQ-9 CCC 0.6050 vs MulT 0.0760。E-DAIC 二分类 Macro-F1 0.6937（full search）vs 次优 0.6814。另一配置 GPT-6 Astra PHQ-9 CCC 0.1999 领先、二分类 Macro-F1 0.4559 低于 MulT 0.5165（诚实报告部分劣势）。选择规则对照：incumbent 选择平均测试 Macro-F1 0.6843 vs 经典 1-SE 0.4991、最大分选择 0.4876——不确定性感知继承有效。进化 memory 使标记对齐斜率相对无 memory 审查提升 0.0049 [0.0003,0.0092]。成本：每完成 run $0.76 vs $0.74。搜索广度消融：full search 并不一致最优，但覆盖差异混淆（320 vs 24/15 次评估）。所有报告数字标 seed-0/多 seed 平均（遵守其各自协议）。

## 创新点
1. 把多模态临床管线开发形式化为经验 RSI（retained pipeline+expanded candidate space+accumulated experience 三件继承）；2. subject 对应不变性检查（GSC）——RSI 反馈可靠性的数据层保障；3. 不确定性缩放接受裕度+保留裕度理论界——小样本验证集上的继承决策有原则；4. incumbent 选择规则消融实证"最大分选择"在噪声下崩溃（0.6843 vs 0.4876）。

## 局限
临床领域特定（抑郁检测），管线=特征工程+经典预测器组合而非记忆系统；"研究记忆"是实验经验教训，非感知记忆内容；无视频记忆内容级错误概念；部分任务不敌强基线；搜索消融受覆盖-成本混淆。
