# OEP: Poisoning Self-Evolving LLM Agents via Locally Correct but Non-Transferable Experiences (2026, arXiv 2605.18930, 上海交通大学)

## 问题与动机
- 自进化 agent 的反思-记忆巩固机制本身是攻击面。现有记忆攻击（AgentPoison 触发后门、MINJA 查询注入、MemoryGraft 语义模仿植入、Zombie Agents 休眠）注入的 payload 都含显式恶意指令/触发器/可验证错误，易被内容过滤、A-MemGuard 类异常检测或 LLM-as-Judge 审计拦截。
- 核心问题："纯干净样本能否诱导 agent 在记忆中自生成有害规则？"——利用反射式 agent 的三个已知失败模式：视角禁锢（observational selection bias）、对自生成反思的非对称信任（provenance-weighted trust，自己反思出的规则审查更松）、风险敏感规则归纳（安全对齐带来的损失厌恶）。还引用"experience-following behavior"与 agent 自发 misevolving 现象为攻击面依据。

## 方法拆解
- **威胁模型**：低权限黑盒（用户级交互），不可改系统提示/参数/记忆库/工具；只能提交构造样本 e_adv 经标准记忆巩固管线进入情景历史。受害系统形式化：认识论校验器 V 过滤→反思函数 R 从过滤后历史提取全局规则 M_{t+1}=M_t∪R(Ĥ_t)，更新后的语义记忆作为全局先验影响未来独立会话。目标：完整性破坏（下游错误率最大化）+可用性破坏（Denial-of-Wallet，冗余工具调用膨胀成本）。
- **三阶段管线**：
  1. Clean Edge-Case 构造：边界任务 t_e+非标准方法 m_e 的解 s_e，须满足局部正确性 O(t_e,s_e)=True 且全局不可迁移 E_t~D[S(t,m_e)]<ε（LLM 生成边界条件+自动经验过滤）；
  2. ACT（Adversarial Consequence Triplet）：e_adv=(t_e,s_e,c_adv)，c_adv 是"不采用 s_e 将发生极端但领域可信的灾难"（如致命内核恐慌/误诊）的假想后果——用期望效用理论论证：放大感知损失→收窄反思假设空间→把攻击者目标规则 r_obs 的蒸馏概率 P(r_obs|s_e) 从≪1 抬到主导（softmax 视角的形式化）；
  3. 用户级注入：agent 自己处理、自己反思、自己把局部经验固化为高优先级过度泛化规则。
- **训练方式**：无训练；全 prompt 层攻击。

## 数据与实验
- 三域：Math（GSM8K）、Healthcare/Med、Tool。指标 ESR（OEP 注入体验证成功率）/ASR（攻击成功率，下游退化）/ACC。
- 主结果（GPT-4o）：Math ASR 59.14（ACC 从 ~96 掉到 54.29）、Med 52.00、Tool 71.93（步数 +1.69）——三域 ASR>50%。Gemini-2.5-flash 60.29/52.57/71.05、DeepSeek-V3.2 53.14/43.71/66.67、Qwen3-max 58.00/50.29/72.81；GPT-4o-mini 仅 ~30 → **能力-脆弱性悖论**（越强的模型因指令遵循与安全反思更严格反而越易被劫持）。
- ACT 消融：仅 QA ASR 8.86/5.26/7.02；QA+Solution 14.57/10.29/17.54；完整三元组 59.14/52.00/71.93——"事实正确本身不足以投毒，负效用信号是关键"。
- 持久性：50 次良性查询后 ASR 仍高（Tool 域 72%）——高感知风险使规则压过自然记忆稀释。
- 防御对抗：LLM 恶意内容审计器把 MINJA/AgentPoison 等显式恶意基线 ASR 压到 <15%，OEP 仍保持 40.29%。
- 重复三次实验，标准差 <2%。

## 创新点
1. 提出并形式化"clean-label 记忆投毒"：攻击对象不是记忆内容而是反思/巩固过程本身（认知劫持效用计算），绕过一切内容级防御。
2. ACT 三元组构造法——用"严重但可信的假想后果"武器化安全对齐的损失厌恶。
3. 机制分析把 provenance 信任不对称、视角禁锢、风险敏感归纳串成因果链，并给出两个针对性防御方向（蒸馏时主动检索多样案例打破视角禁锢；多 agent 交叉质询再固化）。

## 局限
- 攻击需较高对抗样本比例才见效（低比例被良性上下文稀释；100% 比例时最强）——现实混合比例下的效果未报；非自适应对手（未测对手探测阈值）。
- 防御侧只有初步方向（主动检索+辩论），无成熟修复机制：被污染的过度泛化规则如何定位/撤销/重写未解决。
- 纯文本域（数学/医疗/工具），无多模态记忆。
- 评测依赖"会话记忆+反思更新"的具体 agent 形态，对无反思机制的系统不适用。

## 与本选题关系
- **撞车风险：中低（攻防视角）**。
- **overlap**：直击我们闭环的软肋——我们的"证据驱动经验固化/策略进化"若缺乏对经验可迁移性与证据多样性的审计，局部正确经验会固化成有害全局规则；OEP 的三失败模式（视角禁锢/自生成信任偏置/风险敏感归纳）就是我们修复机制设计时必须抵抗的归纳偏差清单；其"主动检索多样案例再固化"防御方向与"证据驱动验证"同源。
- **difference_from_ours**：OEP 是攻击论文，目标是证明脆弱性；我们做的是防御性能力建设——对（无论恶意还是自然产生的）错误记忆/规则的证据驱动定位与修复。可作为"为什么需要 transferability-aware memory validation beyond content auditing"的关键引文（其原话），并在 related work 的安全条目中与 MemLineage 并列：MemLineage 管投毒内容溯源、OEP 管干净样本诱导的错误规则，两者都未提供修复算子——正是我们的空间。
