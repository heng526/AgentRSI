# A Survey of Agent Memory in the Second Half: Towards Self-Evolving and Long-Horizon Agents (2026, arXiv 2602.06052 v4, UIC/Salesforce/Google 等 50+ 机构综述，OpenReview 已评审)

## 问题与动机
- AI 进入"下半场"：从刷分转向真实长程效用（agentic coding、deep research、computer use、具身）。上下文爆炸超出固定窗口，agent 必须跨交互持续积累、管理、选择性复用信息。
- 核心论点：记忆已从被动存储变为 agent 自进化的基底（substrate）——短期记忆门控经验感知/选择/抽象，长期记忆把经验固化为可复用知识与技能，构成"从自身经验改进"的闭环。2025 年记忆论文数百篇，该综述系统化 218 篇。

## 方法拆解（三维分类 + 操作 + 学习策略）
- **记忆基底（substrate）**：外部（向量索引/文本记录/结构库/层次库）vs 内部（权重/隐状态/KV cache），并给出权衡分析。
- **认知机制**：sensory / working / episodic / semantic / procedural 五类功能。
- **记忆主体（subject）**：user-centric（个性化）vs agent-centric（任务经验）。
- **操作机制**：单 agent 五操作（存储索引、加载检索、更新刷新、压缩摘要、遗忘保留）；多 agent 四种记忆架构（private/shared-workspace/hybrid/orchestrated）+ 三种路由 + 隔离与一致性（写控制、反馈环一致性）。
- **进化与优化策略（§5，核心）**：三层递进——(1) prompt 驱动（静态规则/动态控制）；(2) 微调把策略内化进参数（策略内部化、稳定化与边界控制、效率与检索精炼）；(3) RL 记忆策略（step 级记忆决策、trajectory 级记忆表示、跨 episode 与多 agent 记忆）。指出记忆管理正成为可训练的自进化能力，并延伸到显式可移植可共享的 agent skills（harness/context engineering/MCP 类协议）。

## 数据与实验
- 综述无自建实验；统计 218 篇论文（2023Q1–2025Q4）三个维度的累计发表趋势，2025 年急剧加速。
- 评测整理：指标三类（accuracy / similarity / LLM-as-judge）；值得注意的记忆专项指标——Memory Integrity（抽取记忆是否覆盖必需记忆点）与 **False Memory Rate**（存储/更新/使用中引入伪造或错误记忆的频率）；HaluMem 报告记忆准确率、完整性与 false memory rate。
- Benchmark 分 user-centric（LoCoMo、LongMemEval、PersonaMem、HaluMem 等）与 agent-centric（WebArena、OSWorld、InterruptBench 等）两册。

## 创新点
1. 首个把 substrate×mechanism×subject 三维统一、且以"系统设计视角"组织 agent 记忆的大综述；明确"记忆=自进化基底"命题。
2. 把记忆管理策略的学习路径（prompt→SFT→RL）作为主线，覆盖 RL-learned context curation 与决策时经验固化。
3. 六个 open challenges 精准刻画空白（见下）。

## 局限（其自述的 open challenges，即领域空白）
- §9.1 自进化 agent：现有方法重推理期复用、缺原则性固化与泛化；经验驱动的后训练存在负迁移、不受控漂移、语义不一致风险；需要连接经典持续学习与结构化记忆的统一框架与新基准。
- §9.5 多模态/具身记忆："当前系统缺乏 action-conditioned 记忆更新、跨模态抽象、跨 episodic/semantic/procedural 层一致性维护的原则性机制"；错位或过时记忆导致技能碎片化与复合误差；建议 world-model 视角（记忆更新=受控隐状态转移、proactive memory planning、记忆与世界模型互训）。
- §9.6 评测：现有基准掩盖 provenance tracking、矛盾消解、长期策略一致性等记忆关键能力；呼吁 versioning/audit/rollback、provenance 元数据、资源-效用权衡度量。

## 与本选题关系
- **撞车风险：低（综述，但为最强"选题正当性"引文）**。
- **overlap**：§9.5 逐条列出我们选题的痛点（多模态记忆一致性维护缺失、stale memory 致复合误差）；§9.6 的"矛盾消解/审计/回滚/provenance"诉求与我们的"证据驱动记忆错误定位→局部修复"几乎同构；§9.1 的"漂移/负迁移/语义不一致"对应我们跨任务策略进化的安全边界。False Memory Rate 指标可作为我们实验的现成评测维度。
- **difference_from_ours**：作为综述只提出方向不提供机制；没有面向视频记忆（M3-Agent 类）的具体错误定位/修复算法，也没有任何实验验证。引用策略：用 §9.5+§9.6 论证 gap 的权威性，用其 taxonomy 把我们的工作定位为"agent-centric × 多模态 × 修复型演化"的交叉点。
