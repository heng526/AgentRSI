# NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness (2026, arXiv 2609.08183)

## 问题与动机
RSI 需要一个具体机制让系统观察自身能力并把证据转化为下一轮学习。作者主张已部署的 routing harness 天然携带该机制：agentic 交互除任务输出外还留下执行轨迹+模型能/不能做什么的可观察证据。现有 agent 后训练把交互记录当静态监督，没有利用"部署系统对每次交互预测并记录了能力需求（routing tier）"这一系统性反馈信号。目标：把 routing harness 的数据飞轮变成 harness 介导的 RSI 原型。

## 方法拆解
- **数据飞轮**：异构模型池+智能路由 harness（含 OpenSquilla），C0–C3 四服务档位（bounded 低风险→通用→多步推理执行→最大能力），每 turn 记录预测档位/策略调整/实际服务档位（prediction–action–outcome 分离）。语料 10⁵–10⁶ 条 harness 轨迹+公开数据。质量控制三级：规则化结构验证（完整/可恢复/隔离三出口）→六维语义评估（goal attainment/instruction adherence/tool use/evidence consistency/error recovery/termination，PASS/WARN/FAIL，缺证据不判正）→subscene 级三轴标注（Scene/Goal/Outcome）。
- **进化闭环（evaluation–selection–update loop）**：每轮在分层评测套件上评当前 checkpoint→按属性/质量维/结局/路由档聚合出**模型缺陷画像（deficiency profile）**→下一轮训练混合向薄弱区域倾斜（数据分配而非专门失败目标）→更新模型回部署产生新轨迹暴露新缺口。
- **训练方式（改权重，与冻结基座相反）**：① routing-guided 三阶段课程 SFT——用重估的能力需求分（hard=tier index/soft=score 加权均值）排序 user-turn 样本，低分样本保留在后期防尾部被高需求主导；② routing-guided on-policy distillation——同一三阶段调度起始上下文，学生在自身生成前缀上被固定教师以 top-K+1 分箱 reverse-KL 监督，rollout checkpoint 持续刷新。基座 Qwen3.5 4B/9B。

## 数据与实验
十个基准（harness agent/工具使用/代码/指令遵循/交互）。4B：宏均 58.94→64.87；9B：65.60→69.04；最大增益在 harness 类与执行密集型评测；后训练 4B 大幅缩小与 9B 基座的总体差距。Agent trace 分析显示训练闭合端到端执行回路、规模在反馈与失败信号下兑现（"Scale pays off under feedback and failure"）。

## 创新点
1. 把 routing harness 的预测-决策-结果记录当作 RSI 的能力观察通道与课程信号（routing score 作 curriculum ordering proxy 而非难度标签——明确指出实际服务档位混入用户覆写/服务可用性不能当标签）；2. capability-guided data allocation 的缺陷画像驱动数据再分配闭环；3. 六维证据接地语义评估+确定性结构门的质量管线；4. routing 引导从 SFT 自然延伸到 on-policy distillation。

## 局限
训练报告/原型性质，RSI 闭环只走了一轮（作者自认"initial prototype"，多轮可持续性未验证）；改权重路线与我们冻结基座设定相反；能力信号是路由档位估计而非记忆内容级错误定位；无多模态；基准数字无置信区间/种子说明。

## 与本选题关系
撞车风险：**低**（改权重的模型训练路线，与外置记忆路线正交）。
overlap：同属"用系统自身运行产生的证据驱动下一轮改进"的 RSI 大框架；其 deficiency profile → 下一轮数据分配，与我们的"错误定位→定向修复"在"评估反馈定向改进"层面同构；结构验证+六维证据接地评估可借鉴为我们修复候选的记忆质量门。
difference_from_ours：它改模型权重（agentic post-training），我们冻结基座只进化外置记忆；它没有记忆内容错误的概念（改进对象是模型能力分布），无多模态。引用价值：在 related work 中作为"RSI-训练侧"的代表与"记忆侧"（我们）区分定位；其 prediction–action–outcome 分离思想可用于我们修复闭环的归因记录设计。
