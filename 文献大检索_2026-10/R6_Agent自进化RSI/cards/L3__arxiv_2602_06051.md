# CAST: Character-and-Scene Episodic Memory for Agents (2026, arXiv)

## 问题
多数智能体记忆只做语义召回（KV/向量/图三种范式），无法表示与检索连贯事件（who-when-where）：KV 对抽取敏感、向量检索混淆相似与相同、图记忆依赖抽取质量且易碎片化。

## 方法要点（记忆/进化/修复机制）
- 戏剧理论启发的双记忆：语义记忆沿用 HippoRAG2（OpenIE 三元组图+DPR）；情景记忆把对话消息窗（view，w=1）按"时间/地点/话题"三维距离贪心聚类成 scene（经典三一律），场景内按"是否发言"分主角 MC/配角 SC，人物流上把场景序列汇总为 character profile。
- 检索：语义图+DPR 与 scene 嵌入 kNN 并行，实体/时间/地点过滤；融合为轻量重排——语义结果中同时命中情景结果的条目前置，不引入新候选。
- 离线索引+在线查询，冻结基座（gpt-4o-mini 生成，Llama-3.3-70B 做 NER）。

## 实验与数据（benchmark+主指标）
- LoCoMo + epbench（ep_default/ep_scifi/ep_news）；F1 与 LLM-as-a-Judge（J），每方法跑 5 次取均值。
- locomo_open：CAST F1 62.02/J 81.21，超最强基线 Zep（48.78/72.89）+13.24 F1/+8.32 J；ep_scifi J 97.06、ep_default J 93.12 均第一（HippoRAG 94.49/91.30 为第二）。
- 总体平均较基线 +8.11% F1、+10.21% J；较 naive RAG +26.54% F1、+32.12% J；最高单项提升 F1 +24.25%、J +46.59%。
- 消融：去短窗 view 构造 locomo_open J -13.38；去角色标注时间类查询退化；固定槽位注入（slot3）不如重排融合。

## 创新点
用戏剧理论的"场景（三一律）+角色档案"作为情景记忆的一等组织单元，人物条件化的场景检索显著提升 who-when-where 类问题；语义+情景的轻量重排融合不增加候选。

## 与本选题关系
撞车风险：中低。属冻结基座下的记忆表示/检索架构创新，无错误定位与修复、无进化机制；但"事件级（scene）记忆单元+时间地点锚定"对多模态情景记忆的证据定位结构有借鉴意义；文本对话域。
