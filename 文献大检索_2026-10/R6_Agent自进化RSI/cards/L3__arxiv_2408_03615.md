# Optimus-1: Hybrid Multimodal Memory Empowered Agents Excel in Long-Horizon Tasks (2024, arXiv 2408.03615, Peng Cheng Lab/HIT)

## 问题
开放世界（Minecraft）长时序任务中，MLLM 智能体缺乏结构化世界知识与多模态历史经验；现有智能体只存单模态信息或直接存成功案例，无法像人一样从"知识+经验（含失败）"两类长期记忆中学习。

## 方法要点（记忆/进化/修复机制）
- 混合多模态记忆（免参数更新）：HDKG 分层有向知识图（节点=物体，有向边=可合成关系，检索子图+拓扑排序得到任务所需材料关系）；AMEP 抽象多模态经验池（视频 1fps 过滤→16 窗口图像相似度动态抽象→MineCLIP 对齐文本子目标后存池，并纳入环境/初始状态/计划；成功与失败案例均入库）。
- 框架：Knowledge-Guided Planner（视觉观察+HDKG 子图一次性生成完整子目标序列）+ Action Controller（STEVE-1 鼠标键盘低层动作）+ Experience-Driven Reflector（周期激活，检索 AMEP 经验判定 COMPLETE/CONTINUE/REPLAN，REPLAN 触发 Planner 修订计划）——失败检测→计划修复闭环。
- 非参数自进化："自由探索-教师引导"交替，多实例共享同一 HDKG/AMEP，记忆随迭代增长，从易到难。

## 实验与数据（benchmark+主指标）
- Minecraft 长时序任务基准（MineRL，任务组 Wood/Stone/Iron/Gold/Diamond/Redstone/Armor），成功率 SR：Wood 98.60、Stone 92.35、Iron 46.69、Diamond 11.61、Redstone 25.02、Armor 19.47，较现有智能体最高提升达 30%（Iron 组 46.69 vs Jarvis-1 36.15、DEPS 16.37）；GPT-4V 零样本为 0。
- 多 MLLM 骨干（Deepseek-VL、InternLM-XComposer2-VL 等）+混合记忆获得 2-6 倍性能提升；4 个周期×160 任务的自进化实验显示成功率随记忆扩充持续上升。

## 创新点
1. 知识图+多模态经验池的双通道记忆（失败案例入上下文学习）。
2. 经验驱动反思器做子目标级失败判定与计划修复。
3. 免参数的"探索-教师"自进化记忆增长。

## 与本选题关系（撞车风险：中低）
同样是"冻结模型+经验记忆+反思修复"的代表作，REPLAN 机制即任务内修复；但修复粒度是整段计划重规划而非证据级错误定位，领域为 Minecraft 文本/低层动作而非通用多模态，自进化仅限记忆池增长。可作为基线相关工作引用。
