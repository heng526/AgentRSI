# RoMeRL: Balancing Feedback Coverage and the Memory-Reward Trap in Self-Evolving Agent Memory via Reduced-Order Utility States (2026, arXiv 2608.02508)

## 问题与动机
学习型 agent 记忆（用下游任务结果在线优化记忆效用、不更新 LLM 权重）面临两个耦合难题：(1) **反馈稀释**——轨迹索引效用随交互历史无限增长，有限反馈摊薄到不断扩大的状态空间，导致普遍效用冷启动（Cold-Q）、低反馈密度；(2) **Memory-Reward Trap（MRT）**——轨迹级奖励共同分配给共同召回的记忆，弱相关/噪声/过期经验在成功回合中被"搭便车"式正更新。实验证明用 UCB 加强探索虽提高覆盖但降低任务性能——探索-污染困境。核心问题：如何在不扩大暴露于错误奖励传播的效用支撑集的前提下提高反馈覆盖。

## 方法拆解
- **问题形式化**：轨迹索引效用 Q̂ᵢ 估计的是观察效用 μᵢ=E[R|retrieved] 而非边际贡献 θᵢ（interventional 差），credit gap = 任务基线 v⁰ + 观察归因偏差 aᵢ。Theorem 1 给 gap-方差分解 E[(Q̂−v¹)²]=aᵢ²+σ²/nᵢ；Theorem 2/3 证明全池估计需要随 Nₜ 对数增长的反馈预算；MRT 定理表明更强探索不消除 credit gap 反而扩大错误正更新。
- **降阶记忆状态**：把每任务不断增长的效用空间替换为固定 4 维状态 Z=[z⁺C, z⁺A, z⁻C, z⁻A]，按结果极性（正/负证据）×记忆动态（consolidated 历史证据 / adaptive 状态转移证据）笛卡尔积分解：PCC（正固化）、PAC（正自适应）、NCC（负固化）、NAC（负自适应）四个语义坐标，内容随新经验更新或**替换**（replacement，含继承 warm start Q 值），反馈集中在有界支撑上。role-guided 机制：无效轨迹不生成程序化记忆（省 LLM 调用）。
- **进化闭环**：非参数运行时 RL（标准 Q 更新 Q←Q+α(r−Q) 作用在固定坐标上），冻结 LLM；理论刻画错误坐标的稳态占用。
- **训练方式**：无 LLM 训练；纯记忆效用在线学习。

## 数据与实验
LifelongAgentBench（OS/DB）+ ALFWorld（6 任务型）+ AppWorld，10 epoch，冻结 backbone（DS-V4-flash/GPT-5.4-mini/GPT-5.6-luna）。Overall 宏均 0.753 vs 最强全基准基线 MemRL 0.724（+2.9 点）；LAB-OS 0.824/0.838、LAB-DB 0.680/0.952、AppWorld SGC 0.286→0.326（TGC 0.306 vs 0.313 略低）。效率：Cold-Q 比率 -80.0%（MemRL 从 29%升到 44.9%，RoMeRL 从 28%降到 9.0%）、反馈密度 4.96→29.93（6.0×）、记忆池 -84.4%（45K→7K）、LLM 调用 -21.1%（570K→450K）。MRT 受控压力测试（OS，首轮 10% 噪声条目）：MemRL+UCB 正噪声更新 7.2、终噪声率 1.20%、SR 78.4%；RoMeRL 2.4、0.15%、SR 82.0%。跨模型记忆迁移：LAB-OS GPT-5.4-mini 67.0→81.6（+14.6）、Gemini-3.5-flash 74.0→81.4（+7.4），步数均降。消融：容量匹配对照 MemRL-4（每任务限 4 条）仍输给 RoMeRL，说明收益来自结构化降阶而非单纯小池。

## 创新点
1. 提出 Memory-Reward Trap 概念并给出因果分解（observational vs marginal utility, credit gap）；2. 降阶效用状态（4 坐标极性×动态分解+替换继承）替代无限增长轨迹索引，理论+实验双验证；3. 证明"结构化降阶"优于"容量限制+反馈感知替换"（MemRL-4 对照）。

## 局限
纯文本/具身玩具任务（OS/DB/ALFWorld），无多模态记忆；坐标替换可能丢掉长尾罕见但关键的记忆（4 条/任务上限的容量代价未在主实验分析）；效用仍是轨迹级奖励的观察值，credit gap 只是被"压缩支撑集"缓解而非消除；AppWorld TGC 略低于 MemRL；单配置单 run，无种子方差。

## 与本选题关系
撞车风险：**中低**。
overlap：同属"冻结 LLM 下记忆系统自进化"主线；其 MRT（错误记忆被错误强化）本质是记忆错误的传播问题，与我们"错误定位+修复"的动机相通；其"替换+继承"机制是一种隐式记忆修复（旧错误内容被驱逐）。
difference_from_ours：它通过**预防性状态压缩**抑制错误累积，不做证据驱动的错误定位（不知道哪条记忆内容是错的，只学效用），修复粒度是"坐标"而非语义条目；文本任务，无视频/多模态。对我们选题的价值：提供了"错误效用累积"的理论语言（credit gap、噪声占用率），可借用来论证多模态记忆修复中"为何需要定位而非全量重写"；其 Cold-Q/噪声率指标可借鉴为修复机制评测指标。
