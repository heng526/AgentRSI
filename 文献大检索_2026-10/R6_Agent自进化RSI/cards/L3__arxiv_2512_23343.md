# AI Meets Brain: Memory Systems from Cognitive Neuroscience to Autonomous Agents (2025, arXiv)

## 问题
现有智能体记忆研究囿于单一学科视角，对生物记忆机制吸收不深；缺乏认知神经科学与 LLM 智能体记忆的统一综述。

## 方法要点（记忆/进化/修复机制）
综述框架（非方法论文）：
- 记忆定义沿"认知神经科学→LLM→智能体"递进；LLM 侧分参数记忆/工作记忆/显式外存。
- 分类：nature 维（episodic vs semantic）+ scope 维（轨迹内 vs 跨轨迹）。
- 存储位置（context window 的 memory folding vs 外部 memory bank）与格式（文本/图/参数/潜在向量）。
- 管理全生命周期：提取（flat/hierarchical/generative）、更新（轨迹内刷新 + 跨轨迹保留/遗忘，含艾宾浩斯遗忘曲线、RL 学习保留-遗忘策略、自主知识重构）、检索（相似度 vs 多因子 recency/importance/Q-value）、应用（上下文增强 vs 参数内化）。
- 记忆安全：攻击（提取、投毒后门、噪声干扰）与防御（检索源净化、响应拦截、隐私保护）。
- 未来方向：多模态记忆（符号化 vs 特征级压缩 vs 混合证据表示）与跨智能体技能共享（Agent Skills、统一记忆操作语言）。

## 实验与数据（benchmark+主指标）
综述无自建实验。系统盘点记忆 benchmark：语义向（LoCoMo、LongMemEval、MemBench、HaluMem（记忆幻觉，83k）、Evo-Memory（自进化记忆）、MemoryBench、LifelongAgentBench 等），按 Fidelity/Dynamics/Generalization 三属性标注；情景向（web 搜索、工具使用、具身交互域）。Evo-Memory 与 HaluMem 与"记忆错误/自进化评测"直接相关。

## 创新点
首个认知神经科学与智能体记忆的统一交叉综述；提出 nature×scope 二维分类与记忆评估三属性（保真/动态/泛化）标注体系；把记忆安全（攻防）纳入记忆研究版图。

## 与本选题关系
撞车风险：低（综述，非方法）。可作相关工作与 benchmark 选型地图；其指出的开放问题——多模态统一记忆表示、压缩导致语义退化、记忆更新中的错误修正（Dynamics 属性）——恰为本选题（多模态记忆错误定位与局部修复）提供立论依据；未见与"证据驱动错误定位+局部修复"正面撞车的已有工作。
