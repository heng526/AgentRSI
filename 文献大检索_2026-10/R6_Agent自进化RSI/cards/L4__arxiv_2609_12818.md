# Online Video Agent Harness for Long Video Understanding / VideoXAgent (2026, arXiv 2609.12818)

## 问题与动机
长视频理解中两条主流路线都有缺陷：(1) LMM 直接塞帧——均匀降采样可能漏掉 query 相关关键帧并引入无关帧干扰，长视频上下文百万 token 级导致 context degradation；(2) 现有视频 agent（DVD、HAVEN 等）依赖 query-agnostic 离线预处理（分段/均匀采样/离线解析成数据库或层级记忆）再 agentic 检索——继承固定采样的漏证据问题且全视频开销前置。提出纯在线 agentic 范式：从原始视频文件+query 出发按需取证据，不物化 query-agnostic 索引。另指出视频 agent 的工具集多靠人类直觉 ad hoc 选择，缺系统能力结构依据。

## 方法拆解
- **架构**：ReAct 式 orchestrator（默认 Claude-Opus-4.6，视觉弱/纯文本亦可）+ 60+ 专家工具（14 个后端家族：VLM 检查、Grounding-DINO/DINO-X 检测、PaddleOCR、WhisperX、PyAnnote、SAM/SAM2、CLIP 检索、FFmpeg 等）。Think-Plan→Decompose-Act→Observe-Reflect→Continue/Finish 循环。
- **能力挖掘（数据驱动工具设计）**：从 MINERVA 人类专家推理 trace (Q,R,A,O) 反推认知轨迹——LLM 抽取原子能力（必须引用 reasoning_evidence 原文防幻觉）→归一合并→all-MiniLM 嵌入+K-means（silhouette 选 K）→人工精修 → 22 个原子能力/5 类（视觉感知/时间关系/空间关系/音视/高层推理），作为工具设计蓝图。
- **客观证据契约**：每个 VLM 工具包共享 objective-evidence 协议——子查询当假设验证而非事实接受；只在当前调用提供的媒体上接地；字幕/OCR/检测输出作为工具生成上下文须与直接可见证据显式分离；不得无证据断言身份/意图/因果/精确计数；返回 {visual_evidence, answer, uncertainty} 结构化三元组——orchestrator 能区分接地观察与解释、跨工具传播不确定性。
- **证据聚合与冲突消解**：每条观察关联来源工具+时间/空间参照；冲突先查是否指不同时间/区域/实体，未决冲突触发精化输入或换工具的定向验证；最终答案只用冲突消解后的证据并区分直接观察与推断。
- **预算控制（防非终止）**：L=125 节点硬上限（约 42 次工具调用），65%/80%/90% 三级递进警告（各一次，指示停止冗余验证、多数表决消解冲突、给出答案）；预算耗尽时 tool_choice=none 强制作答——保证每次运行产出答案。
- **训练方式**：无训练，纯 harness+工具。

## 数据与实验
五基准：VideoMME-Long 85.1%（52.0 帧/~51k 上下文；vs Doubao-Seed-2.0-pro 85.5%@~112k、Gemini-3.1-Pro 86.2%@~179k）；LongVideoBench-Long 78.1%（116.7 帧/55.3k；vs HAVEN 78.2%@943.5 帧、DVD 68.6%@2816 帧）；LVBench 76.5%（无字幕协议，60.8 帧/55k；vs Doubao 76.4%@~96k）；MINERVA 65.7%（Claude-Opus-4.6 orchestrator）——超 Gemini-2.5-Pro-Thinking@256f 的 64.7 与 Gemini-3-Pro-preview 的 65.0，纯文本 GLM-5.2 orchestrator 亦达 65.4，证明性能来自 agentic 工具使用而非原生视觉。Video-MME-v2 分层子集 61.28%（nonlinear 40.74）。消融：objective rules 与预算控制均有量化贡献（217 题 loop-prone 压力集）。

## 创新点
1. 纯在线视频 agent 范式（无预建索引/层级记忆，query 条件化按需取证据）；2. 从人类专家推理 trace 数据驱动挖掘原子能力分类学指导工具设计；3. objective-evidence 契约（假设式验证+不确定性结构化传播）抑制 VLM 顺从子查询预设；4. 递进警告+强制作答的预算中间件解决 ReAct 非终止。

## 局限
无记忆/无进化——每次 query 从零探索，无跨任务经验积累（与记忆型 M3-Agent/WorldMM 是两条路线）；LVBench 等无字幕场景禁用音频工具属协议适配；多 orchestrator/VLM 组合结果依赖闭源 API；MINERVA 是其分类学来源（作者声明只用高层分类学未用实例数据，仍有轻微污染风险）。

## 与本选题关系
撞车风险：**低**（无记忆进化的在线 agent，与我们的记忆修复主线正交但同域）。
overlap：同为视频多模态 agent；其 objective-evidence 契约（证据-解释分离、不确定性显式化）与我们"证据驱动的错误定位"所需的证据可信度分级直接相关；其"冲突触发定向复验"是任务内小修复环的实例。
difference_from_ours：无持久记忆、无跨任务闭环——它通过"不建记忆"回避记忆错误问题，我们处理"记忆已建但可能错"的问题；无策略进化。引用价值：(a) 论证在线 vs 记忆型是当前视频 agent 两大范式，我们属于记忆型但补其缺失的修复环；(b) objective-evidence 契约可作为我们记忆写入与修复验证时的证据分级参照。
