# MMA: Multimodal Memory Agent (2026, arXiv)

## 问题
基于相似度检索的记忆会把过时、低可信、互相矛盾的条目当等可靠证据，触发过度自信错误；且缺乏"证据不足时弃权"的认知审慎评估（accuracy-only 指标激励过度自信）。

## 方法要点（记忆/进化/修复机制）
- 在 MIRIX 之上加元认知可靠性层：每条被检索记忆计算置信分 C=[w_s'·Source + w_t'·Time + w_c'·Consensus]——来源先验映射 + 半衰期指数时间衰减 + 冲突感知网络共识（邻域加权，余弦 Support Factor σ∈[-1,1]，负值=矛盾惩罚）。
- 置信分直接调制推理与弃权：低置信记忆触发 abstain（选择性预测/校准弃权）。
- MMA-Bench：程序化生成 10 sessions（约 6 个月）信念动态基准——可信 User A vs 不可信 User B，四阶段（校准→对抗噪声→陷阱：视觉证据支持不可信方→消解/不可知），逻辑矩阵 A 标准/B 可靠性反转/C 模糊/D 不可知；CoRe（Confidence-and-Reserve）弃权感知打分 + 三步信念探针（SCR 自纠正率/FCR 虚假忏悔率/MSA 模态信号对齐）。
- 发现"Visual Placebo Effect"：视觉输入的存在绕过认知过滤产生证据幻觉（基座模型视觉熵更低、被继承）。

## 实验与数据（benchmark+主指标）
- FEVER（500 样本×3 种子）：MMA 59.93% vs MIRIX 59.87%（持平），种子标准差 ±1.62% vs ±2.50%（-35.2%）；α=0.2 选择性分 0.6484 vs 0.6468；Actionable Acc 71.61±0.43（稳定性最优）。
- LoCoMo：安全导向 'st' 配置（去共识）Actionable Acc 79.64% vs 78.96%，错答 298 vs 317，Utility 883.6 最优。
- MMA-Bench：Type-B（可靠性反转）Vision 模式 MMA 41.18% Type-B 准确率，基线 0.0%；Type A MMA 50.0% vs 基线 0.0%（认知瘫痪）；Type D MMA CoRe 从 Text 0.69 崩到 Vision -0.38（自暴露视觉安慰剂效应）。
- 消融：去 Source → 确定性场景 0%（认知瘫痪）；去 Time → Vision Type A 0%；去 Consensus → Type D -0.69（幻觉）。

## 创新点
把可靠性建模下沉到记忆条目级（来源/时间/共识三信号）并直接驱动推理与弃权；首个联合控制"来源可靠性先验×时序演化×结构化图文矛盾×弃权感知打分"的多模态信念动态基准；命名并量化 Visual Placebo Effect。

## 与本选题关系
撞车风险：中高。同样做"多模态记忆中的矛盾/不可靠条目定位"（置信评分+冲突感知共识），是本选题最直接的近邻之一。差异：MMA 只在检索时降权/弃权（post-retrieval 过滤，作者自述无法补召回缺失），不做记忆库内错误条目的证据驱动定位改写与修复，也无跨任务策略进化；其 MMA-Bench 逻辑矩阵与 CoRe 打分可直接复用为本选题评测组件。
