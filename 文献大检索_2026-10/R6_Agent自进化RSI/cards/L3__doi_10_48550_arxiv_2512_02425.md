# WorldMM: Dynamic Multimodal Memory Agent for Long Video Reasoning (2025, arXiv 2512.02425 / CVPR 2026, KAIST)

## 问题
长视频（小时到周级）推理中，现有记忆增强方法过度依赖文本表示（字幕/摘要），视觉证据在推理时缺位；固定时间尺度、固定检索数量的设计无法覆盖跨度差异巨大的事件；纯视觉上下文又会分散注意力。

## 方法要点（记忆/进化/修复机制）
- 三类互补记忆：情节记忆（多时间尺度 t0<t1<…<tN 的知识图谱组，事实三元组）、语义记忆（持续演化的 KG，存关系/习惯等长期概念知识）、视觉记忆（分段特征嵌入 + 帧级时间戳索引双通道）。
- 记忆修复机制（与选题最相关）：语义记忆的增量整合 Consolidate(G_ts^k, T_ts^{k+1})=(G\T_remove)∪T_update——用嵌入相似度找出新旧三元组中重叠/冲突项，交由 LLM 判定应删除的过时/冲突三元组与需修订/新增的三元组，实现概念级错误定位与局部修删。
- 自适应检索 agent：迭代选择（记忆类型, 查询）二元组或 STOP，按查询动态决定模态与时间粒度；PPR 图检索+跨尺度 LLM 重排。

## 实验与数据（benchmark+主指标）
- 5 个长视频 QA 基准（EgoLifeQA、Ego-R1 Bench 周级；HippoVlog；LVBench、Video-MME(L) 小时级），准确率。
- WorldMM-GPT 平均 69.5%（EgoLifeQA 65.6 / Ego-R1 65.3 / HippoVlog 78.3 / LVBench 61.9 / Video-MME(L) 76.6），较最强基线 GPT-5（61.1）高 8.4%；WorldMM-8B 平均 59.9%（较 Qwen3-VL-8B 51.6 高 8.3）。
- 消融：视觉记忆带来 +4.2%（E+S+V vs E+S）；语义记忆使 HabitInsight 达 76.9%（较 E+V +23%）。

## 创新点
1. 文本+视觉双模态、多时间尺度的三记忆架构与自适应模态/粒度选择检索 agent。
2. 语义记忆的 LLM 仲裁式三元组冲突消解（删除/修订），即持续运行的 KG 记忆纠错。
3. 周级视频上对记忆式方法的系统性验证。

## 与本选题关系（撞车风险：中）
其语义记忆整合算子（冲突三元组定位→LLM 判定删/改）就是多模态记忆错误定位+局部修复的一个实例，撞题风险需认真对待；但差异明确：WorldMM 的演化仅限单一视频流内的语义 KG 整合，无跨任务经验记忆、无策略层进化、无失败驱动的反思回路。本选题可强调"任务级策略进化+失败证据驱动的错误定位"与之划界。
