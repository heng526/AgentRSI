# 3DLLM-Mem：面向具身 3D 大语言模型的长期时空记忆
# （3DLLM-Mem: Long-Term Spatial-Temporal Memory for Embodied 3D Large Language Model）

## 二、一句话总结

针对 3D-LLM 在多房间、长时程具身任务中无法维护"空间×时间"长期记忆的问题，同时贡献两点：一是 **3DMEM-BENCH** 基准（基于 HM3D+Objaverse 构建，26,276 条训练轨迹、2,892 个测试任务 = 1,860 具身任务 + 865 情景记忆 EQA + 167 长时程描述，含 simple/medium/hard 细粒度分级与 in-the-wild 泛化挑战）；二是 **3DLLM-MEM** 模型——以 LLaVA-3D 为底座，用**工作记忆 token（当前观测）作为 query**，通过可学习的记忆融合注意力从存储历史观测的稠密 3D **情景记忆库（episodic memory bank）** 中按任务相关性选择性融合关键-值特征，在最难的 in-the-wild 具身任务上以 32.1% 平均成功率超过最强基线 16.5 个百分点。

## 三、研究问题与动机

人类在陌生房屋中为泰迪熊找礼盒时，会自发构建 3D 认知地图、维护工作记忆、形成跨空间时间的情景记忆并规划行动；而现有 LLM/3D-LLM 做不到。作者指出两大根因：**(1) 长期记忆链断裂**——真实 3D 场景信息稠密，长时程任务的每个细节都可能重要（如必须记住沿途见过的每个礼盒及其与泰迪熊的适配结果），全量塞进上下文会爆长度，选择性检索（Embodied-RAG 等）又会漏掉关键信息；稠密 3D 表示能保留几何关系与环境细节，但如何高效存储与检索稠密 3D 记忆是悬而未决的基础问题（作者自称是首批把稠密 3D 表示作为具身 3D-LLM 记忆的工作之一）。**(2) 空间与时间记忆纠缠**——智能体既要追踪物体在哪，又要追踪物体如何随探索与交互而变化，环境演化中保持已有空间表征的一致性并纳入新信息超出当前模型能力。现有基准（ALFWorld、Behavior-1K、VisualAgentBench、EmbodiedBench）均为单房间/短时程、不要求长期记忆（表 1 逐一对比），OpenEQA 等记忆 QA 也不支持具身动作，因此需要新基准 + 新模型双管齐下。

## 四、方法详解

### 4.1 3DMEM-BENCH 基准构建

**环境**：HM3D 语义数据集（1000 个 3D 空间、10,600 房间）经轴对齐包围盒与有效语义标签过滤后剩 182 个场景、2,602 个房间（平均每场景约 18 房间）；因 HM3D 物体在 Habitat 中不可交互，从 Objaverse（800K 3D 物体）注入交互物体。**轨迹生成**：沿用 box-demonstration-instruction prompting，把房间与物体的轴对齐包围盒（AABB）喂给 Gemini 生成多房间长时程任务与轨迹，并要求"指令模糊化 + 延迟回忆"（不许开头列清单，须在轨迹后段召回早期观察）与"记忆更新换决策"（原计划物体找不到时改用替代物）；用轨迹仿真流水线逐步校验（1）智能体位置、（2）引用物体存在性、（3）拾取/放置动作合法性（单手持物约束、房间匹配、终局不得持物），过滤后**通过率约 24%**，再由 4 名学生专家对照多视角渲染图人工复核。**任务三类**：具身任务（跨多房间动作链，分 simple/medium/hard；另有 in-the-wild 挑战，如"Force Finish：停止探索立即上早餐"这类训练中未见的novel设定）；长期记忆 EQA（五子类：空间关系、长期物体导航、跨房间比较推理、多房间布局理解、语义物体计数，专门考察记忆随时间/空间的变化）；情景记忆描述（总结已探索房间的共性 + 与当前房间的差异）。评测时考虑智能体回答问题时的站位。

### 4.2 3DLLM-MEM 模型与记忆机制

**底座**：LLaVA-3D——CLIP 编码多视角图像为 2D patch，用深度图与相机内外参得到 3D 位置嵌入 P，加到 2D patch 特征上构成像素对齐的 3D patch X³D，再用最远点采样（FPS）降采样到固定 N 个 token；上下文窗口扩到 8192。**双记忆系统**（仿人类工作记忆/情景记忆分工）：当前观测 X[t=i] ∈ R^{N×d} 留在上下文窗口内作为**工作记忆**；历史观测 X[t=1:T] ∈ R^{T×N×d} 存入**情景记忆特征库**。**写入（Episodic memory）**：对每个时刻 j 的观测，先用 MLP 投影到记忆专用特征空间再入库；并加正弦位置编码表征时间步 t=j，直接加到记忆特征上，使记忆带上时间戳。**读取（Memory fusion，核心公式）**：把工作记忆的 3D 特征编码到共享记忆空间作为 query f^Q_t ∈ R^{N×M}，记忆库存有历史观测的 key f^K ∈ R^{T×N×M} 与 value f^V ∈ R^{T×N×M}（T 为历史步数、N 为每步记忆 token 数），做缩放点积注意力：f^Q_fuse = Softmax(f^Q_t (f^K)^⊤ / √C) · f^V（C 为缩放维度，即标准的 query-key 相似度加权求和 value），再将融合特征与工作记忆拼接 f^M = Concat(f^Q_fuse; f^Q_t) 作为最终记忆增强表示送入 LLM。即"**当前观测决定回忆什么**"的任务相关软检索，端到端可学习。**更新（Memory update）**：工作记忆在线动态更新，环境变化立即反映在 3D 表征中；智能体进入新环境时，旧工作记忆转入情景记忆库；**若该环境已存在于库中且被智能体修改过，则就地更新对应记忆条目**——记忆库始终反映已探索环境的最新状态（环境变化与对应观测预先收集、本地存储以加速训练/推理加载）。**训练**：SFT 标准语言建模损失，微调记忆模块 + LLM 解码器（从 LLaVA-3D 预训练权重初始化），Adam lr 2e-5、无 weight decay、3% 线性 warmup（1e-8→1e-5）后余弦衰减。

## 五、实验与主要结果

**基线**：(1) 3D-LLM（微调版，Q-Former 每房间 32 token、冻结 T5-flanxl 骨干、512 上下文截断）；(2) Everything in Context（仅小规模场景可行，全观测入上下文）；(3) Most Recent Memory（只保留最近观测）；(4) Retrieval-Augmented Memory（RAG，检索最相关历史观测拼入上下文）；(5) 3D-Mem（CVPR 2025 的快照式 3D 场景记忆，配 GPT-4o / Gemini-2.5-Flash / Gemini-2.5-Pro，不支持具身交互）。

**具身任务（表 2a，SR/Sub-SR%）**：3DLLM-MEM in-domain：simple 45.5/73.4、medium 36.8/67.8、hard 30.5/46.2；in-the-wild：simple 37.0/65.4、medium 31.6/57.4、hard **27.8/42.1**；平均 in-domain 37.6/62.5、in-the-wild **32.1/55.0**。对比：RAG 平均仅 22.3/41.6（in-domain）与 15.6/28.3（wild），Most Recent Memory 21.1/39.3 与 13.7/25.3；**最难设定（hard in-the-wild）下基线跌至约 5%（RAG 4.8、MRM 5.4），3DLLM-MEM 仍保持 27.8%**——即摘要所称领先最强基线 16.5 个百分点（32.1 vs 15.6）。值得注意 Everything in Context 在 simple 上达 35.5/63.9，**优于 RAG 与最近记忆**，说明上下文放得下时全量信息最有效，但仍不及 3DLLM-MEM 的选择性融合。3D-LLM 因上下文限制连 simple 都只有 10.4%。

**EQA 与描述（表 2b）**：3DLLM-MEM 全面最优——空间关系 62.8、长期导航 40.6、比较推理 41.4、布局 39.9、计数 26.3（对比 3D-Mem Gemini-2.5-Pro：39.7/27.7/36.0/35.2/16.4；RAG：38.0/33.4/31.8/29.7/15.6）；描述任务 BLEU1/BLEU4/METEOR = 58.2/18.8/37.3（3D-Mem Flash 42.8/4.8/29.6，3D-LLM 42.3/12.0/30.6）。3D-LLM 描述尚可但 EQA 崩溃（空间关系仅 2.9），印证其长时程时空推理短板；3D-Mem 靠聚合图像记忆在 EQA 部分子项尚可但导航/计数弱。定性案例（图 4、图 6）展示"布置阅读角"任务中跨房间回忆两本书与茶杯位置并逐一定位取回的全过程。

## 六、消融与分析

消融聚焦记忆融合 query 的初始化方式（表 3，具身任务 SR%）：**以工作记忆 token 初始化**（本文方案）平均 in-domain 37.6 / wild 32.1；**以最近的情景记忆初始化**平均 32.4 / 22.5；**以可学习零参数初始化**平均 32.9 / 23.3。有趣的反转现象：最近记忆初始化在 simple 上略优于零初始化（42.3 vs 41.4 in-domain），但在 hard 上反而更差（22.6 vs 24.2 in-domain；wild hard 15.3 vs 18.6）——作者解释为最近记忆初始化倾向与邻近时刻观测融合，对简单任务够用且收敛快，而零初始化完全靠训练监督学会"什么记忆最有用"，故难任务上更稳健。结论：用当前工作记忆作为 query 是最有效且最鲁棒的设计，也再次印证"回忆应由当下任务情境驱动"的动机。其他分析散见于正文与附录：RAG 式文本/特征相似度检索在具身长时程设定下提升有限（相对 Most Recent Memory 仅 +1.2 平均 SR），说明**检索瓶颈不在"找到相似记忆"而在"找到对任务有用的记忆"**；Everything in Context 强于 RAG 的现象进一步说明现有检索式记忆管理会漏关键信息。

## 七、局限性与批判性评述

作者自述：**不含低层导航与控制策略**，动作执行依赖模拟器中预定义的高层策略（<GO TO ROOM>/<PICK UP> 等离散动作 token），声称这与记忆研究正交、未来可集成——但这意味着系统离真实机器人还有"动作落地"的整层距离。批判性看还有：(1) **评测与数据生成的循环依赖**——轨迹与 QA 均由 Gemini 生成（约 24% 校验通过率意味着 76% 的生成内容被丢弃，成本高且残余偏差未知），开放式 EQA 又用 Gemini 做 LLM-as-judge 评分，生成与评判同源存在系统性偏好风险；(2) **记忆库随 T 线性膨胀**——情景记忆按时间步全量累积特征（T×N 个 key-value），文中没有遗忘、压缩或分级淘汰机制，注意力计算量随记忆增长，可扩展性未在超长轨迹上验证，也未与"摘要式/物体中心"记忆在同等 token 预算下公平比较；(3) **统计严谨性不足**——Checklist 承认因 TPU 成本未做多次运行、无误差棒；(4) 描述任务用 BLEU/METEOR 等弱代理指标；(5) "就地更新被修改环境的记忆条目"在仿真器中可由状态簿记直接实现，但论文未说明特征空间中如何检测与表达"该条目已过期"，这一更新机制若迁移到开放环境会困难得多；(6) in-the-wild 挑战虽然不同于训练分布，但仍在同一模拟器与场景族内，泛化主张的外推有限。

## 八、对读者研究的启发

读者做"多模态 Agent 长时程记忆 + 递归自改进 RSI"，基于 M3-Agent 做持久记忆纠错与修复策略迁移，本文启发：**(1) "就地覆盖"式记忆更新是纠错的底层原语**——3DLLM-MEM 的 Memory update 规定：环境被智能体修改后，记忆库中对应条目被更新而非追加，记忆库始终反映最新状态；这正是持久记忆纠错想要的语义（新证据推翻旧条目时改写而非堆积矛盾条目）。M3-Agent 的文本/多模态持久记忆可借鉴此原则设计"写前查重、冲突即覆写"的策略，并显式记录条目的修改时间戳（本文用正弦时间编码的思路可推广为条目级元数据），为后续一致性审计提供依据。**(2) 检索应当由当前任务状态条件化且可学习**——消融显示以工作记忆为 query 的融合显著优于固定/零初始化，而外部 RAG 基线提升有限甚至不如全量上下文；对读者而言，这意味着持久记忆纠错中"取出哪些记忆来校验/修复"这一步本身就值得训练或至少任务条件化设计，不能只靠相似度检索；M3-Agent 可把当前感知与任务上下文编码为 query 去探询记忆库，把"怀疑哪些记忆有错"也变成一个可学习的软注意过程。**(3) 用"记忆变化 QA"探测记忆腐化**——3DMEM-BENCH 的 EQA 专门考察记忆随时间/空间的改变（物体被移动后旧位置是否还成立、跨房间计数是否一致），这类探针任务可直接移植为 M3-Agent 记忆库的健康巡检集：定期对持久记忆自问"基于新观测，哪些条目已失效"，检测漂移与矛盾，再触发修复。**(4) 双论文对照出的方法学光谱**——Optimus-1 代表非参数、案例式、免训练的记忆自进化（RSI 落在记忆扩容上，改错成本低、可即时生效），3DLLM-MEM 代表参数化、潜空间、需 SFT 的记忆融合（表达强但每次改进都要重训）；读者做 RSI 时可取中间态：以非参数记忆库承载可纠错、可迁移的修复策略（失败案例即修复示范，参考 Optimus-1 的成败双库结论），以轻量可训练模块（如本文的融合注意力或一个小型相关性打分器）承载检索策略的渐进改进。**(5) 基准设计可复用**——simple/medium/hard 分级 + in-domain/in-the-wild 双轴 + 记忆变化 QA 的评测框架，非常适合用来度量"记忆修复策略迁移"是否真正带来分布外鲁棒性，避免只在训练分布上自证改进。
